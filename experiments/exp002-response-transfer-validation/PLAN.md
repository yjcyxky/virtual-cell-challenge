# 原生计数响应迁移与生成校准

2026-09-26：根据 [leaderboard 诊断](../../docs/leaderboard-score-interpretation.md)实施四项改进。本研究延续 exp002 的共享响应、NTC 相似性迁移及训练背景内校准；exp004 是另一个正在运行的共享参数 CVAE 研究，不在此修改或重复训练。既有 exp002 历史 run 及其评估定义保持不变。

## 研究问题与方法

1. 在同一数据与输出尺度下，背景条件残差能否比共享靶点响应改善未见背景预测？共享响应为各训练背景靶点响应的等权均值；条件残差为 NTC 相似性加权均值减共享均值。共享系数和残差系数由训练背景内部留一预测的完整充分统计量拟合，残差向零正则化。超参数和系数不得读取外层留出扰动标签。
2. 原生测量轴监督是否补足公共 6,114 基因之外的信息？复用已审计 CountData 与固定计数缓存，在各背景全部可靠测量轴计算先聚合计数、再 log1p(CP50K) 的响应。缺测保留 NaN；训练、拟合、指标均不以零填充标签。无任何训练测量的 readout 明确用零响应/输入 NTC，记录支持掩码。最终模型使用五背景，包含 H1；记录仍无监督的官方 readout 和未见靶点。没有合格靶点标签时使用训练背景的平均响应作显式回退，并由独立校准系数收缩。
3. 保持预测响应均值相同，比较经验 NTC 模板与逐基因独立负二项计数生成。模板通过行列比例拟合使列均值接近目标并保留所抽 NTC 的总计数分布，再随机舍入为整数。零响应且无深度变化时模板生成严格为 NTC 复制。NB 的逐基因离散度只由特征 NTC 拟合。这是生成方式对照，不宣称恢复扰动后的完整联合分布。深度响应只从训练扰动拟合，不从留出真实细胞推定。
4. 五个完整背景轮流留出，最终在所有五背景上重拟合。解析/受约束的小型二次优化代替长时间训练；训练完成条件是所有准入训练任务纳入统计、所有预定内部背景完成、优化器收敛且参数有限，随后完成五折评估与最终拟合。不存在自设时间预算触发的训练完成。

## 数据、划分和估计对象

输入为 `exp003/20260923-mcvae-true-s17/cache/data` 的已登记只读缓存，来源 H1 三面板、K562 GWPS、RPE1、HepG2、Jurkat。保留原细胞身份、计数、基因安全映射、准入与 NTC 分半；验证内容哈希及来源摘要。不修改原缓存及其中历史 reserved 标记，本 run 按当前全部准入任务训练。

每个靶点使用全部缓存独立细胞的等权计数均值，每个背景使用固定半池 NTC；特征半池作为推断输入，参照半池用于响应标签和评价。该估计对象与 exp003 的构件/batch 等权主损失不同，但与本地官方评估按实际缓存细胞组成聚合一致。缓存仍是既定抽样，不冒称所有原始细胞。背景与技术因素可能混杂，另报告 NTC 分半偏差和细胞深度/检出诊断。

内部校准只用外层训练背景：训练背景之一作为内部留出，其余生成共享及相似性残差；只在双方可测的 readout、排除 on-target 后积累每任务等权、每背景等权的误差。基因轴交集只用于 NTC 相似性距离，响应监督使用可测轴并集。每折模型的有效训练上下文与统计量来源单独保存。

## 基线与评价

全量准入外层任务报告 CP50K 响应 MSE/MAE、方向/相关、预测和真实幅度，以及已见/未见靶点、具有/缺少靶点响应监督的 readout 分层。基线为零响应、未校准共享响应、已校准共享响应，主方法为校准共享响应加背景条件残差。所有方法比较同一任务与同一基因轴，不丢弃没有 donor 的任务。

官方方法本地评价面板：每背景最多 300 个靶点，以固定 seed 和 `(context,target)` 哈希排序选取，与表达、效应、模型输出无关；H1 不足 300 时取全部准入靶点。每靶点保留全部准入缓存细胞，NTC 使用固定参照半池。每个背景的面板和身份在训练前固定并落盘。以该同一面板构建 generic-response baseline 与五次拆半参照，使用固定 `cell-eval2` 0.16.0 / commit `5e64833518a6603a0301cbe28185d49c30f4a986`、完整 vcc2026 六项、gpudge/CUDA，不修改官方评分或筛选标准。

每折比较 NTC 模板基线、校准共享响应模板、条件响应模板、相同条件响应的 NB 生成，生成种子 101/202/303。报告 raw、scaled、参照与分母，不把面板分数混同 exp003 的全任务分数或官方 A/B/C 分数。NTC 空干预额外报告半池均值/方差、零率、总计数均值与 CV，以及官方同一 DE 流程的显著基因比例。主要模型选择先按五背景等权的本地官方综合分，平分时偏向简单共享模型；选择使用过的背景明确为开发验证。该选择不改变各折已经归档的结果。

最终模型在五背景全部准入任务重拟合，生成官方 A/B/C 各 300×400 个整数计数细胞，保留预测并检查官方轴、细胞数、计数及稀疏上限。官方 validation 的提交按用户选择执行；已用于选择的官方反馈是开发反馈，不是独立最终测试。

## 运行、恢复和交付

`./reproduce.sh --scope calibrated_counts --run-id <id> --config configs/native-count-transfer.json` 完成环境检查、输入核验、统计、训练、五折评估、全背景拟合和官方预测准备；追加 `--submit` 才执行一次官方提交。所有阶段同一 run/W&B 身份；缓存与预测属于该 run。恢复校验原配置、代码文件、锁文件与数据摘要，复用已完成的确定性统计/模型/评分，不混合不同条件。

尚未产生任何完整统计、训练 checkpoint 或预测时，可用 `--preparation-repair <原因>` 登记等价的准备阶段代码修复；仅允许源码身份变化，配置、数据和环境变化仍须新建 run。旧 config 完整归档并记录新旧 commit，检查日志追加，修复后重新运行验证。已有训练结果时不允许此例外。

本方法无需随机梯度优化器；每折 checkpoint 保存所使用的源响应、掩码、上下文、充分统计量、最优系数、温度、深度系数和校准曲线。生成使用每任务固定种子与配置；原子完成标记保证中断后重放未完成任务。正式执行先提交代码与 uv.lock，活动期不修改代码或环境。W&B 使用 yjcyxky/virtual-cell-challenge，group=exp002-response-transfer-validation，id=run_id，模型和结果上传版本化 Artifact，不上传原始细胞。

交付的 `response-library.npz` 与各折/final JSON checkpoint 可独立加载；`ResponseLibrary` 校验库和 checkpoint 身份，只加载 checkpoint 准许的训练背景标签。正式 A/B/C 推断从归档模型重载，验证推断不依赖预处理统计缓存。Artifact 包含参考分数 bundle、逐任务 raw/aggregate/scaled 指标、生成诊断和拟合模型；大型本地计数预测保留在 run 内并记录哈希。

完整交付要求五折有效训练/评估、所有预定生成对照、最终五背景模型、可追溯预测与指标、REPORT 结论及代码清理。负结果仍为有效结果，启动或测试通过不算完成。
