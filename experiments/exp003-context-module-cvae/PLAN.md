# 状态条件化模块的联合计数生成

需求、决策和进度：[Issue #32](https://github.com/yjcyxky/virtual-cell-challenge/issues/32)。本轮只报告本地结果，不提交官方评分。

## 假设与范围

在新背景只提供 NTC 和靶点的条件下，有语义的可重叠基因模块及其背景/状态依赖，能否改善 CRISPRi 响应和单细胞联合分布？不要求恢复唯一因果网络。RNA 中未观测到的关系不直接判假。负结果是有效结果，不把均值预测或 NTC 模板缩放称为联合分布学习。

使用已登记的 H1（2025 三个靶点面板，重复 NTC 仅保留一次）、K562 GWPS、RPE1、HepG2、Jurkat 原始计数及 exp002/20260922-c 固定身份/划分账本。排除药物、刺激和 Cas9。所有输入只读。输出轴采用已固定的 2026 基因轴；各来源的未测量基因进入编码与似然掩码，不能当成零观测。没有合格监督的基因单列，不宣称完成其预测验证。

同一背景多面板采用各面板与特征 NTC 共同具有可靠身份的 readout 交集。H1 Training 中 HSPA14/LRTOMT 的 symbol 与 Ensembl 冲突，而 Validation/Test 缺少 Ensembl 佐证；不能以较宽松面板的符号映射覆盖这一冲突。原始缓存保留原值，分析通过显式掩码排除，并写入 readout-support 记录。编码器包含基因位置的缺测表征和靶点是否被测量的标记，区分缺测与观测零。

## 实验因素与估计对象

技术 batch 使用源数据的 Flex batch 或 GEM group；guide A|B 是一个构件，不当作两次重复。NTC 按固定 half_20260921 分为特征池和独立响应参照池。每个技术层两池各至少 8 个 NTC 才有共同支持；每个背景×靶点至少 50 个有支持的扰动细胞。所有排除原因和保留权重落盘。

训练按背景、靶点、构件、技术层依次等权采样，再在层内均匀选细胞。固定缓存以 128 个扰动细胞/靶点为通常上限，按构件和技术层分配；若非空层超过 128 个，则上限扩到层数，保证每层至少一个细胞；NTC 每池每技术层最多 64 个。此上限是预先规定的单细胞抽样设计，结果只针对该估计对象，不能冒称使用全部细胞的似然。缓存选择只看身份和固定随机数，不看表达/效应。保存每层原始、缓存细胞数与实际概率。

主指标按构件和有共同支持的技术层标准化，再对靶点及背景等权。另按原始扰动细胞比例汇总同一批预测作组成敏感性分析，并报告 batch/构件间效应差异、NTC batch 方差与深度关系。预测按可用 NTC 技术层产生条件分布，评估器使用已声明的任务技术层权重；不把这些事后技术层比例输入响应网络。另报该靶点有支持的技术层占全部合格 NTC 技术层的比例。没有扰动共同支持的 NTC 层可以用于未来部署输入，但本轮不能给其泛化性能制造 ground truth。无真实 batch 的官方接口以后只能对 NTC 可观察分组建模，不能把 ntc_id 冒充培养批次。

时间、效应器、平台和培养条件保留在元数据，但与细胞背景重合的作用不可单独识别。测序深度、细胞周期和存活群体变化可能含真实响应，不统一回归删除。状态是 NTC 推定的连续代理，不是细胞类型 ground truth；不做前后细胞真配对，不解释潜变量路径为真实生物轨迹。

## 模型和先验

使用小型条件潜变量负二项计数生成器。仅在训练背景 NTC 上拟合公共基因 PCA；新背景 NTC 可以变换、计算状态混合和均值。条件先验从 NTC 状态混合、背景统计和靶点学习扰动后的潜变量分布、混合权重与幅度。后验编码器在训练中看扰动计数；预测只从条件先验采样。解码器在匹配 NTC 均值的对数偏置上学习共享随机模块、背景/状态门控的基因连接以及受限低秩基因残差，并用同一响应分量的非负加性诱导路径允许 NTC 零观测基因出现表达；计数离散性由负二项分布生成。均值偏置不是复制 NTC 细胞，联合依赖来自学习的共享随机潜变量。

固定 STRING v12 功能/物理网络、Reactome GMT、GOA 正向注释（排除 NOT），按知识语义分别建模块。模块选择只用固定知识覆盖和大小，不用留出响应。无方向 STRING 分数不解释为激活/抑制或因果强度。成员是软连接锚，学习到的有符号载荷及状态门控允许成员贡献改变；保留弱的模块外连接和相同容量残差，不强制同模块基因同向。

拟合前在每个训练折检查 NTC batch 内模块联合变化、相对匹配随机模块的支持，并对照未按 batch 中心化的结果，以及扰动后的保持/破坏/重组。只在训练折估计支持权重，证据不足的模块保留至少 0.25 连接锚权重。权重先作用于软连接，再使用固定的未加权成员度数尺度，避免把低支持权重重新归一化消掉。这些统计是观测证据，不是机制真实性概率。随机先验用二部图换边保留模块大小和基因成员度数；不把已筛选的真先验参数泄漏给无先验对照。

目标为有掩码的负二项变分损失和 KL 加热，同时监督从条件先验生成的群体计数均值相对参照 NTC 的响应。辅助响应量为 `log1p(CP10K(pseudobulk mean counts))`，与 `mean(log1p(CP10K(cell)))` 明确区分；后者从实际生成整数细胞评估，不用均值代替。

## 对照、划分和选模

关键对照：真实先验、保持成员度数的随机先验、无先验可学习模块，均运行种子 17、29、43；同一划分、计数损失、残差容量及优化配置。附加预定消融使用种子 17：移除状态依赖的扰动作用、移除背景依赖的扰动作用、关闭残差、关闭模块扰动作用。`no_state` 保留背景依赖但关闭扰动对状态混合的重排与逐细胞状态门控；`no_context` 进一步移除背景响应条件，是静态响应对照，保留生成基线所必需的 NTC 统计。二者是嵌套消融，不把 `no_context` 的总差异当作背景单因素的因果效应。`no_module` 同时封闭潜变量重排影响模块的旁路，允许受限残差使用先验靶点特征；`no_residual` 保留各模型共有的可学习 on-target 标量通路。先报告单种子消融的有限证据，不将其当三种子结论。

五次完整背景留出，固定背景顺序 H1/K562/RPE1/HepG2/Jurkat。外层背景只允许 NTC；下一个背景为内部跨背景选模集，其余三个为训练集。这是明确的三背景训练、一个内部验证、一个外部测试设计，不声称每折训练了其余全部四背景。20% 靶点由固定哈希全局保留，训练/内验证不使用这些靶点的扰动标签；外测试分别报告见过靶点和背景/靶点均未见。内部验证任务按固定身份哈希最多 128 个，用于停止；外测试覆盖全部合格靶点。最后用五背景非保留靶点按各折最佳轮数中位数拟合交付模型，保留严格未见靶点身份。所有五背景已参与项目开发，评估属于回顾性开发评估。

每次拟合最多 16 轮，每轮 512 个优化步；至少 8 轮，之后内部跨背景响应误差连续 4 轮无改善早停。任务分背景使用无放回循环队列，并报告真实训练覆盖；不把一次轮数称为遍历所有细胞。选模主量是按任务等权的伪 bulk 响应 MSE；生成分布诊断同时记录，明显崩坏不能宣称成功。三种子统计不冒充独立生物重复。

## 评估与交付

共同测量轴及各背景完整可测轴分别报告生成样本的相对 NTC MSE/MAE、方向/相关性、响应幅度；独立列 on-target。联合分布报告固定训练 NTC PCA 空间的 energy distance、协方差误差、投影分位数距离；状态混合只在固定 NTC 代理空间中比较。报告检测比例、均值/方差和深度分布。每靶点生成 128 个细胞作评估；若技术层超过 128 个则至少每层一个，并保存真实生成数。保存代表性完整整数预测及所有任务的均值/分布统计，不上传原始单细胞。主模型预测均值来自有限生成样本，因此误差含 Monte Carlo 分量；数学零响应基线没有这一分量，比较偏保守，不能把差值全部归因于生物机制。原始均值计数误差和深度分布也单列，检查归一化的组成效应。

基线在同一缓存、任务和权重上重算：NTC 零响应分布和跨训练背景共享响应。历史 #30/#31 分数仅作历史记录，不拿不同估计对象的百分比当直接比较。对任务配对差异做靶点簇 bootstrap，分别报告五背景和三种子分布；只有五背景，不声称总体泛化置信保证。

每个 variant×seed 是独立 run，折内拟合与最终拟合属于该完整试验。统一入口检查环境/身份、准备、训练、评估；完整 checkpoint 保存模型、优化器、随机数、采样队列/游标、轮数/步数、最优状态和早停历史。恢复沿用 run，改条件/从头训练新建 run。正式训练使用已提交代码与 uv.lock，W&B 一一对应，断网本地记录后同步。模型/关键结果版本化，REPORT 写结论和局限；Issue 管任务状态。交付前清理本轮临时代码和失效实现，历史 run 与用户文件保留。

可用 `--reuse-run` 显式引用已完成 run 的固定计数缓存、同一折 PCA、共享响应基线和同种先验诊断，逐文件核对 SHA256、数据条件、训练背景、代码和依赖版本。模型、优化器与训练随机状态不复用。仅优化前的同配置校验修复可用 `--repair-validation-reason` 接续原 run；保存原 config 和代码修订记录，已有优化标记/checkpoint 时禁止此例外。GB10 的统一内存与文件页缓存竞争通过已完成读取文件的 `posix_fadvise` 提示处理，不更换驱动或基础环境。

跨提交复用预处理必须核对生成这些产物的实现身份：data/state/priors、RNA 身份工具和基因映射工具的 Git 对象一致，共享响应的计算/写入分支及其导入、模型构造中的先验准备调用的 AST 一致。已有缓存的提前返回读取分支不参与生产签名；读取修复须另证读取值不变。模型或恢复流程修复可以不改变这些实现；仅凭提交不同不强制重复计算，也不能仅凭配置相同接受已经改变的准备算法。记录生产/消费提交、实现身份、源 Artifact 和每个复用文件的 SHA256。

补充交付检查：`no_context` 的扰动均值、状态变化和离散度条件都关闭背景输入，保留经验 NTC 均值/离散度；属于嵌套消融。首次优化前保存完整初始 checkpoint；轮末只在验证、选模和早停状态完成后保存，验证失败时从前一个完整 checkpoint 重放最后的间隔。测试比较模型、优化器、调度器、随机数、采样器和完整历史。

有限样本 NTC 基线与模型使用相同的构件×batch 分配、样本数和群体权重，从特征 NTC 池抽样，与同一独立参照池定义响应。数学零响应基线仍单列。新增量不改变既有指标或生成随机流；旧 run 缺少这些补充字段时，只在任务和既有基线逐项一致后，将相同固定数据上计算的有限样本 NTC 基线加入比较表，历史文件不改写。

完整生成样本同时保存来源可用 readout 掩码和训练监督可用 readout 掩码。被掩码位置的占位零不解释为已经验证的预测。较早版本的样本文件须结合该 run 的基因映射与 readout-support 记录读取，不能脱离元数据使用。

最终 run 可用 `--compare-runs` 引用其余已完成试验，在同一 run 内完成矩阵比较与归档。比较按背景等权、相同种子和靶点配对；bootstrap 先平均各固定种子的逐靶点差异，再按靶点簇重采样，同时保留各种子的独立结果。区间描述这些背景/种子下的靶点抽样不确定性。比较核对源配置、逐任务指标和 Artifact 身份。原 `target_seen_in_training` 仅表示候选训练集合；另从完整 checkpoint 精确重放采样，记录选中轮次前真正进入优化的靶点，核对末态采样队列/RNG，并对实际暴露、严格保留、先验覆盖分别分层。固定步数加早期选模造成的覆盖不足必须报告。

若所有训练、评估及 Artifact 上传已经完成，只有最后的记录更新失败，可用 `./reproduce.sh --run-id <原 run_id> --finalize-only` 重试收尾。入口要求原环境身份不变、全部完整 checkpoint 已完成，并重新核对远程固定版本及每个归档文件摘要；禁止修改训练条件，不执行优化或重新评估，不覆盖原配置、模型、指标或失败记录。完成记录及 W&B 分别列出原训练提交和收尾代码提交。未完成训练、缺少/改变产物时不能使用此路径。

同一 Experiment 的独立 runs 可以并发，但必须持有环境共享锁。只有没有活动 run 时才能持独占锁执行 `uv sync --locked`；成功后记录锁文件、项目依赖、基础 Python 和已安装包 METADATA/WHEEL/RECORD 的指纹。每次启动核对指纹，通过后使用 `uv run --locked --no-sync`，运行期间不重装任何库。已锁定 cuSPARSELt 0.8.1 的 wheel 内部标记为 `manylinux2014_sbsa`，导致 uv 的常规同步检查会反复建议同版本重装；这里核对实际同步后环境的完整元数据指纹，不忽略之后的变化或更换依赖版本。run 配置保存该环境身份。

启动器通过固定基础 Python 的标准库调用 `micromamba run -n virtual-cell`，为 micromamba 的临时进程登记使用独立缓存，避免主机中断遗留的空登记文件阻塞入口；uv/Python/W&B 子进程恢复原缓存设置，环境共享锁由启动链持有。没有更换基础环境或绕过 uv。完整训练 checkpoint 和选中模型都先写临时文件、刷新文件到磁盘，再原子替换并刷新目录；临时文件刷新失败时不替换此前有效的文件，目录刷新失败也会报错。主机重启后仍须校验中间产物，归档损坏文件并从完整状态恢复；这不等于保证所有文件系统或硬件故障下都无损。
