# 状态条件化模块的联合计数生成

当前训练协议：[Issue #33](https://github.com/yjcyxky/virtual-cell-challenge/issues/33)；损失设计与进度：[Issue #34](https://github.com/yjcyxky/virtual-cell-challenge/issues/34)。历史矩阵与审计见 #32 和 REPORT。本轮只报告本地结果，不提交官方评分。

## 假设与范围

在新背景只提供 NTC 和靶点的条件下，有语义的可重叠基因模块及其背景/状态依赖，能否改善 CRISPRi 响应和单细胞联合分布？不要求恢复唯一因果网络。RNA 中未观测到的关系不直接判假。负结果是有效结果，不把均值预测或 NTC 模板缩放称为联合分布学习。

使用已登记的 H1（2025 三个靶点面板，重复 NTC 仅保留一次）、K562 GWPS、RPE1、HepG2、Jurkat 原始计数及 exp002/20260922-c 固定身份/划分账本。排除药物、刺激和 Cas9。所有输入只读。输出轴采用已固定的 2026 基因轴；各来源的未测量基因进入编码与似然掩码，不能当成零观测。没有合格监督的基因单列，不宣称完成其预测验证。

同一背景多面板采用各面板与特征 NTC 共同具有可靠身份的 readout 交集。H1 Training 中 HSPA14/LRTOMT 的 symbol 与 Ensembl 冲突，而 Validation/Test 缺少 Ensembl 佐证；不能以较宽松面板的符号映射覆盖这一冲突。原始缓存保留原值，分析通过显式掩码排除，并写入 readout-support 记录。编码器包含基因位置的缺测表征和靶点是否被测量的标记，区分缺测与观测零。

## 实验因素与估计对象

技术 batch 使用源数据的 Flex batch 或 GEM group；guide A|B 是一个构件，不当作两次重复。NTC 按固定 half_20260921 分为特征池和独立响应参照池。每个技术层两池各至少 8 个 NTC 才有共同支持；每个背景×靶点至少 50 个有支持的扰动细胞。所有排除原因和保留权重落盘。

训练按背景、靶点、构件、技术层依次等权采样，再在层内均匀选细胞。固定缓存以 128 个扰动细胞/靶点为通常上限，按构件和技术层分配；若非空层超过 128 个，则上限扩到层数，保证每层至少一个细胞；NTC 每池每技术层最多 64 个。此上限是预先规定的单细胞抽样设计，结果只针对该估计对象，不能冒称使用全部细胞的似然。缓存选择只看身份和固定随机数，不看表达/效应。保存每层原始、缓存细胞数与实际概率。

辅助研究指标按构件和有共同支持的技术层标准化，再对靶点及背景等权。另按原始扰动细胞比例汇总同一批预测作组成敏感性分析，并报告 batch/构件间效应差异、NTC batch 方差与深度关系。预测按可用 NTC 技术层产生条件分布，评估器使用已声明的任务技术层权重；不把这些事后技术层比例输入响应网络。另报该靶点有支持的技术层占全部合格 NTC 技术层的比例。没有扰动共同支持的 NTC 层可以用于未来部署输入，但本轮不能给其泛化性能制造 ground truth。无真实 batch 的官方接口以后只能对 NTC 可观察分组建模，不能把 ntc_id 冒充培养批次。

时间、效应器、平台和培养条件保留在元数据，但与细胞背景重合的作用不可单独识别。测序深度、细胞周期和存活群体变化可能含真实响应，不统一回归删除。状态是 NTC 推定的连续代理，不是细胞类型 ground truth；不做前后细胞真配对，不解释潜变量路径为真实生物轨迹。

## 模型和先验

使用小型条件潜变量负二项计数生成器。仅在训练背景 NTC 上拟合公共基因 PCA；新背景 NTC 可以变换、计算状态混合和均值。条件先验从 NTC 状态混合、背景统计和靶点学习扰动后的潜变量分布、混合权重与幅度。后验编码器在训练中看扰动计数；预测只从条件先验采样。解码器在匹配 NTC 均值的对数偏置上学习共享随机模块、背景/状态门控的基因连接以及受限低秩基因残差，并用同一响应分量的非负加性诱导路径允许 NTC 零观测基因出现表达；计数离散性由负二项分布生成。均值偏置不是复制 NTC 细胞，联合依赖来自学习的共享随机潜变量。

固定 STRING v12 功能/物理网络、Reactome GMT、GOA 正向注释（排除 NOT），按知识语义分别建模块。模块选择只用固定知识覆盖和大小，不用留出响应。无方向 STRING 分数不解释为激活/抑制或因果强度。成员是软连接锚，学习到的有符号载荷及状态门控允许成员贡献改变；保留弱的模块外连接和相同容量残差，不强制同模块基因同向。

拟合前在每个训练折检查 NTC batch 内模块联合变化、相对匹配随机模块的支持，并对照未按 batch 中心化的结果，以及扰动后的保持/破坏/重组。只在训练折估计支持权重，证据不足的模块保留至少 0.25 连接锚权重。权重先作用于软连接，再使用固定的未加权成员度数尺度，避免把低支持权重重新归一化消掉。这些统计是观测证据，不是机制真实性概率。随机先验用二部图换边保留模块大小和基因成员度数；不把已筛选的真先验参数泄漏给无先验对照。

## 当前训练目标（2026-09-25，lodo-predictive-loss-v4）

保留架构、先验、NB 条件生成模型、数据准入、五折划分、固定 LR=0.001 及早停协议；按用户要求替换辅助 loss 的统计单位和预测监督。当前方法仍属 exp003，同一 run 内不切换目标。旧目标两侧减去同一观测 NTC 后抵消；单 construct×batch 中重复采样的均值也常只有一个独立细胞，不能作为 16 个独立群体观测。

用户已确认 delta 使用统一归一化表达尺度上的差值。主目标是给定 NTC 背景与扰动靶点，预测各响应基因的 delta；基因关系先验作用于整个条件化响应向量。新目标为 `L = L_delta + lambda_nb*(NB_NLL + beta*KL) + lambda_ntc*L_ntc + lambda_depth*L_depth`，delta 系数固定为 1，其余为辅助生成约束。NB 项仍按每步四靶点加一组 NTC 的 4:1 比例计算，beta 用 2,048 步预热。beta=1 时这部分是条件负 ELBO；辅助项使总目标不再是纯概率下界。保留逐细胞似然训练整个条件计数分布，而不是宣称几个矩能识别完整分布。概率建模参考 [scVI 官方说明](https://docs.scvi-tools.org/en/latest/user_guide/models/scvi.html)，新增组合是本项目待验证的设计。

以 context×target 为统计单位。观测均值使用全部独立缓存细胞，细胞权重为既定构件×batch 层质量除以该层不同细胞数；NTC 使用相同 batch 边际质量和 reference 半池。记录不同细胞数与有效样本数 `1/sum(w_cell²)`。不扩大数据缓存、不将重复抽样视为额外证据。观测统计只为四个训练背景建立，禁止读取留出背景的扰动值。

预测端每靶点按相同 batch 边际质量作 8 次随机分层抽样；每个 batch 枚举全部 4 个状态成分、每成分 2 个高斯样本，保留混合权重梯度。扰动与预测 NTC 使用相同 batch 和高斯基础噪声，降低零响应时的积分噪声；不代表真实细胞配对。原始均值和二阶矩的 Monte Carlo 估计在非线性变换前无偏；经过 log/归一化/Huber 后仍有有限样本偏差。网络未增加构件输入，因此预测的是固定构件组成下的靶点响应。

- `T(mu)=log1p(CP10K(mu))`，先聚合原始计数再变换；基因集合为既定公共轴。`delta_pred=T(mu_pred,target)-T(mu_pred,NTC)`；`delta_obs=T(mu_obs,target)-T(mu_ref,NTC)`。响应项为尺度校准后的加权 Huber，两个预测分支都反传。
- `L_ntc` 将预测 NTC 的 T 均值锚定到独立 reference NTC，避免改变共同基线规避响应误差。
- 固定误差尺度采用加权独立细胞的 delta-method 方差代理，响应尺度合并扰动及 NTC 的估计误差，并加 0.1 的平方下限。NTC 同一 batch 的重复引用先合并质量，不能当成独立参照。扰动方差包含跨层异质性，并非严格的生物重复标准误；记录这一局限，不将其称为置信概率。
- 软响应权重为 `1+4*delta_obs²/(delta_obs²+variance+0.1²)`，范围 [1,5]；保留所有公共基因，不用 DE 硬阈值或 hard-sign 损失，不强制 CRISPRi 靶基因 RNA 为零。
- `L_depth` 在各背景完整测量轴上匹配扰动及 NTC 总计数的均值和标准差，比较 `log1p` 后以 0.25 为尺度的四项 Huber 均值。预测二阶矩显式包括 `E_z[(sum mu)² + sum(mu+mu²/theta)]`，再混合 batch；包含条件 NB 方差和状态/batch 混合差异。它只校准低阶矩，不能保证尾部无异常；官方 1,000,000 计数上限仍严格检查，不裁剪、放宽或跳过失败。

三个辅助 lambda 在每折初始化时，以每个训练背景 4 个固定批次做无优化器梯度校准：NB_ELBO、NTC、depth 相对主 delta 的共享生成参数梯度范数目标比例分别为 0.1、0.25、0.05，按样本中位数设置，系数限于 [0.000001,100]，此后冻结；delta 始终为 1。同时保存限幅后实际初始梯度比例。初始校准不保证训练全程每批次的梯度比例，后续不动态调整目标。这是透明的初始化启发式，不是通过验证证明的最优配比。保存梯度样本、实际系数、统计摘要与哈希到 `cache/<fold>/loss-calibration.json`，实际系数进入完整 checkpoint 和 W&B；恢复时校验不变。规则和各折校准文件引用在 config.yaml 中固定，不使用验证响应估计尺度或系数。

当前只训练 true_prior、种子 17 的五个留一模型；IWAE、投影协方差、生成架构变化暂不叠加。历史矩阵保留其 Git 版本和结果。新版总 loss 与旧版不在同一尺度；用同一官方方法验证结果比较，不能凭不同目标数值的高低宣称改进。

## 数据划分与完整覆盖

H1、K562 GWPS、RPE1、HepG2、Jurkat 五折轮换。每折其余四个背景的全部合格任务用于训练，被留出的完整背景用于验证、选模和早停。全局靶点保留比例为零，不再建立内部验证集，也不再训练第六个全背景模型。官方 leaderboard 数据作为最终测试，本轮不提交。五个已有背景均参与过项目开发，因此结果属于开发验证。

“完整”指既定数据准入及固定细胞缓存内的全部任务；未改成原始所有细胞的似然。引用已完成 run 20260923-mcvae-true-s17 的固定计数缓存。缓存中的旧 reserved 标签不影响细胞选择与数值；新 run 显式核对生产配置、除该标签条件外的所有数据字段及全部文件摘要，记录兼容性证明，训练资格始终由当前配置计算。四背景 PCA/先验证据重新计算，禁止复用旧三背景的拟合产物。

完整覆盖周期以实际采样为准：自上次边界以来，四个背景所有可用训练靶点至少进入优化一次。保留原背景、靶点、构件、batch 层次平衡及无放回靶点队列；较小背景可以重复，不能让大背景被固定步数截断。周期结束不等于每个原始细胞都被使用过。周期内覆盖集合、累计覆盖及队列/RNG 进入完整 checkpoint。

## 固定训练损失监测

每折训练前额外记录一次固定面板初始值（beta=1，仅作参照），之后仍在完整覆盖周期末监测。NB 部分为每靶点按既定训练层质量抽取的固定 4 层、每层 16 个扰动及匹配 NTC 样本，保留 4:1 似然/KL 比例，按 64 层向量化。预测辅助部分独立按全部训练靶点计算，每靶点固定 8 个 batch 抽样及高斯随机数，观测值来自独立细胞的完整加权任务统计，禁止重新使用单层重复细胞均值。每背景记录总 loss、响应/NTC/计数尺度三项、未加权响应和 NTC MSE、零响应 MSE、相对零响应的 skill、NLL、KL；优化日志同时记录加权项，供识别尺度支配。分项系数固定，监测前后参数和训练 RNG 不变。完整抽样面板、任务统计方法/支持与哈希在当前 run 中保存。

四个背景×两个损失构成八条曲线。最近四次监测跨越三个完整覆盖周期，分别要求 (max-min)/max(abs(mean),1e-8) ≤ 0.01。窗口必须连续且首点已达到独立配置的第 10 覆盖周期观察边界；大幅震荡或仍在明显下降都不算稳定。1% 是对固定监测面板的工程判据，不是全部实验层稳定或全局最优证明。相对于 v1，监测目标的估计方法和早停证据范围已改变，历史曲线不能直接拼接。

## 官方方法本地验证

固定 cell-eval2 0.16.0 源码 5e64833518a6603a0301cbe28185d49c30f4a986，使用完整 vcc2026 preset；后端显式固定 gpudge，GPU pseudobulk/PDS 使用本机 CUDA 13 CuPy，依赖由 uv.lock 固定。六项指标的定义、目标基因排除、参考 NTC、Wilcoxon/BH、归一化和逐项截断全部委托官方实现。

每个验证背景使用自身可可靠测量的基因轴，保留全部固定缓存内的扰动细胞和参考半池 NTC，生成预测按相同构件×batch 单元分配同样数量细胞。仍保存按既定平衡权重的辅助研究指标，两种估计对象分别标明。所有验证参考固定；不把未测量基因当成测量零，不改写共享数据。

每个背景建立固定本地 real bundle：均值基线为所有合格靶点原始计数均值的等权平均，按官方常量预测方式评分；本地未另设效力筛选。重复参照使用官方五次不重叠半样本拆分及其 full-gate LFC-NMAE 估计器，base seed 0。必须保留完整六项、有效分母和规则身份；缺失或退化时明确失败，禁止缩小分母、改评分、替换数据。数据集面板、深度、细胞量与官方测试不同，所以这是官方方法的本地验证分数，不能视为 leaderboard 数值等价。

在第 1、4、7 个完整覆盖周期及第 10 周期开始的每个周期运行官方验证；第 2、3、5、6、8、9 周期仍记录训练面板监测但不运行官方评分。被评估的 checkpoint 用固定生成种子 101/202/303 分别生成完整整数预测、计算六项归一化分数和等权综合分；三次综合分的均值用于选模及早停，同时记录分量与标准差。阈值 0.001 是绝对累计改善：与上次重置耐心时的参考分数比较，微小连续改善可以累积。最佳分数单独维护，任意已评估 checkpoint 的实际新高都保存，不受 min_delta 限制。未评估周期保存 null 分数，不能计作无改善；最佳仅指已评估 checkpoint 中最佳，可能错过未评估周期的短暂新高。监测与官方验证耗时分别记录。

## 学习率、早停与恢复

AdamW 学习率全程固定为 1e-3，不进行余弦衰减或学习率预热。使用 factor=1 的 ConstantLR 保留标准训练状态及恢复接口，每次 optimizer step、周期边界及恢复后均保持相同学习率。weight decay 1e-4、梯度裁剪 10 保持原值。KL 系数仍用原来的 2,048 个 optimizer steps 预热，这不会改变学习率。此配置为用户要求的固定学习率重跑，不能在结果产生前宣称更快收敛或泛化更好。

允许停止前必须完成 KL 预热及真实任务覆盖。`stopping_start_cycle=10` 是独立的最低训练覆盖观察边界，保留 v2 的周期安排，不再与学习率或衰减挂钩。在该边界建立耐心参考；其后的三个完整周期同时满足八条训练曲线稳定和验证无有效改善才正常早停，最早第 13 周期末。验证耐心和四点损失窗口分别检查，避免重叠窗口重置造成隐式增加观察周期。未满足则继续；不保留旧十六轮强制完成分支。异常或资源中断保持未完成状态，不能报告收敛。

最佳 checkpoint 可以来自任何已评估的周期，包括训练尚未充分时。训练持续到判据满足，保留最佳和最后状态，报告两者的覆盖、步数与性能。所有阶段属于一个 run；完整恢复模型、优化器、固定学习率状态、采样器/RNG、损失历史、最佳分、耐心参考及计数。监测与本周期安排的评估结束、最佳模型/预测和判稳状态一致后才提交周期末 checkpoint；中断时重放未完成区间，保证同配置恢复等价。v4 从头新建 run 20260925-lodo-response-s17，记录失败的固定 LR run 20260924-lodo-fixedlr-s17 来源；不拼接旧权重、优化状态或监测历史，五折采用一致的初始化与训练协议。

## 评估、版本与交付

每折报告三个生成种子的官方分量/综合分、最佳及最终周期、真实任务覆盖和八条损失的稳定证据。另用原研究评价方法报告 NTC/共享响应基线、MSE/MAE、分布诊断和 batch 组成敏感性；不同于 #32 的划分、任务范围与选模方法必须明确列出，不能据跨口径差异宣称机制改进。

每个验证周期的原始指标、聚合值、分数、配置与校准参照保存在当前 run。保存三套最佳完整生成预测及哈希，并保留代表性预测。关键模型、完整训练曲线、官方评分、校准参照及本地大预测的哈希上传版本化 W&B Artifact；原始参考细胞不上传。

统一入口 ./reproduce.sh --run-id <id> 自动环境校验、测试、输入校验、准备、五折训练和评估。代码、配置、锁文件提交后才正式训练，依赖经固定 micromamba virtual-cell Python 的 uv 管理。整个运行持有环境共享锁；没有活动 run 时才同步依赖。run 与 W&B entity=yjcyxky/project=virtual-cell-challenge/group=exp003-context-module-cvae 一一对应。历史结果、数据与用户文件只读保留。

GitHub Issue 管需求/进度；PLAN 管研究方案，REPORT 管结果。交付必须包含五折有效训练与评估、可追溯模型/预测/指标、W&B 链接和代码清理。预检或单元测试通过不等于完成。模型效果低于基线可作为有效负结果，但只有满足既定训练充分性规则才能称为正常训练结束。
