# 结果与局限

实验：`exp003-context-module-cvae`；需求和执行状态见 [Issue #32](https://github.com/yjcyxky/virtual-cell-challenge/issues/32)。科学方案见 [PLAN.md](PLAN.md)。

本轮尚未完成，不提交官方评分。`20260923-mcvae-true-s17` 在 `f7c6724` 下完成 H1 留出折的训练和 297 个靶点评估；第 9 轮正常早停，选中第 5 轮。随后在第二折先验诊断期间主动中断，状态为 incomplete，不能计为完整 run 或三种子比较的一次完成试验。原配置、训练状态、H1 结果和 [W&B 历史](https://wandb.ai/yjcyxky/virtual-cell-challenge/runs/20260923-mcvae-true-s17) 保留。

中断原因是评估器存在重复整池 NTC 读取：5 个 K562 任务的只读性能分析中，718 次 count 读取耗时 0.911 秒，占总计 1.696 秒的 54%。改为先抽取相同细胞身份、再批量读取，并一次计算生成细胞的逐细胞归一化。模型、损失、数据抽样、评估权重和停止条件不变；验证指标和生成样本与原实现一致后，以新的 run 身份从头训练，不混接训练历史。完整性能和机制结论等待既定矩阵完成。

修复验证：22 项功能测试通过；额外将已保存的真实模型用于五背景共 15 个任务，全部指标和完整生成计数与原评估器逐项完全一致，同机检查耗时从 3.362 秒降至 2.058 秒。该计时是工程验证，不是模型性能证据。

后续协议审查发现两个需要修复的边界：`no_context` 的离散度头仍使用背景输入；轮末训练结束、验证未完成时的 checkpoint 恢复会漏掉该轮验证。前者尚无正式 run，后者不影响未中断训练。先让活动的种子 17 三个 run 完整结束，在隔离 Git 工作区准备修复；后续种子和消融使用修复后的提交。首次优化前与轮末验证中断的故障注入验证已纳入测试，恢复后的完整训练状态、历史和选中模型与连续执行一致。包括完整生成样本附带缺测/监督掩码的检查，29 项测试通过。不会在活动 run 上更新代码。

兼容性验证：六类非 `no_context` 模型在固定输入/参数下的均值、离散度、前向损失和诊断逐项完全一致；保存的真实模型在五背景共 15 个任务上的全部既有指标及完整整数生成数组也与 `db8f339` 完全一致。有限样本 NTC 响应误差是新增评估字段，未修改旧字段。代码版本差异属于已验证的协议修复/补充评估，后续新 run 仍独立从头优化。

种子 17 的前四个背景仍是部分结果，完整矩阵尚未交付。H1/K562/RPE1/HepG2 的真实先验响应 MSE 分别为 0.01536/0.03856/0.01930/0.01304，数学零响应分别为 0.00252/0.00288/0.01282/0.00998；不能称为预测改进。RPE1 与 HepG2 折选中第 1 轮，暴露不足需要单列：RPE1 折选中时只采样过 684/7,185 个合格 K562 训练靶点，523 个 RPE1 测试靶点虽存在于训练候选集合却未实际参与该 checkpoint 的优化。最终表会区分候选集合与真实采样，不改写历史字段。
