## 已核实的限制

- 基础生成校准不足。选中 H1 模型的无干预条件均值总计数，相对特征 NTC 的 batch 中位比为真实/随机/无先验 1.767/1.763/2.523。该诊断每个混合分量采样 16 次、四分量加权，不等于主指标的逐细胞 log 均值；不能只把失败解释为生物知识无效。
- 有限采样不足以解释全部差距。H1、K562 各按固定哈希取前 128 个相同靶点，有限样本 NTC MSE 为 0.003249/0.004623，数学零响应为 0.002718/0.002723，真实先验为 0.015469/0.037848。这是两批任务的事后诊断，不与全任务均值混用；完整矩阵会补充全任务有限样本基线。
- 原 `target_seen_in_training` 指候选训练集合。RPE1 折选中第 1 轮时，只实际采样过 K562 的 684/7,185 个合格训练靶点；523 个 RPE1 测试靶点属于候选训练集合却未参与该 checkpoint 的优化。已精确重放采样队列/RNG 核实。最终比较另报真实暴露，不改写历史字段。
- 非保留合格靶点按既定层权重计算，每组 16 次有放回抽样的期望不同细胞数，H1/K562/RPE1/HepG2/Jurkat 为 2.554/1.077/2.010/1.865/2.060。它不是完整 run 累计细胞数或生物重复数。H1 使用原始完整层的对应期望为 10.503，缓存显著降低层内多样性；K562 原始层也稀疏，对应期望仅 1.423。不能把重复抽样当新增证据。
- Batch 匹配与平衡定义了估计对象，不能分离与背景重合的平台、时间、效应器和培养条件。低支持层协方差、NTC 推定状态和模块 RNA 支持都不是机制 ground truth。PCA 指标只覆盖投影空间；缺少独立生物重复标签，种子和靶点 bootstrap 不能替代它们。
