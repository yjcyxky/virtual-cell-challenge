# 结果与局限

实验：`exp003-context-module-cvae`；需求和进度见 [Issue #32](https://github.com/yjcyxky/virtual-cell-challenge/issues/32)，方法见 [PLAN.md](PLAN.md)。本轮只做本地评估，未提交官方评分。

## 当前状态

预定 13/13 个 run 已全部完成：主模型和两个关键对照各三个种子，四项消融各一个种子。共完成 65 次背景留出拟合与评估、13 次最终五背景拟合，产生 173,199 条任务评估记录。13 个 W&B run 均为 finished，固定 v0 Artifact 已线上核验；最终比较还重放全部 78 次拟合的采样过程，末态队列/RNG 与完整 checkpoint 全部一致。

当前实现没有显示真实先验的总体收益。真实先验的三种子平均 MSE 比匹配随机先验高 2.84%，比无先验高 8.98%；三类模型均劣于 NTC 基线。关闭状态或模块扰动作用能改善单种子总体误差，但收益由 K562 主导。这是此实现及训练/观测条件下的负结果，不能推广为生物先验或状态关系无效。

## 主模型与关键对照：三个种子

响应量为共同 6,114 基因上的 `mean(log1p(CP10K(cell)))` 相对独立参照 NTC 的变化，排除 on-target；每背景内按靶点等权，再对背景等权。每组 13,323 个任务，任务身份及逐任务零响应、共享响应、NTC energy 基线完全一致。下列指标均越低越好。均值 ± 样本标准差来自种子 17/29/43，不是生物重复或泛化置信区间。

每个外折使用三个背景训练、下一个固定背景作内部跨背景选模、一个完整背景作外测试；外背景只向模型提供特征 NTC。全局固定 20% 靶点不进入训练或内部验证的扰动标签。内部选模使用最多 128 个固定任务的 `log1p(CP10K(mean counts))` 伪 bulk 响应，主报告从实际生成细胞计算 log 表达均值，两者不相同。最终五背景拟合用于交付模型，不混入外折测试统计。这五个背景此前已经参与项目开发，因此这些结果属于回顾性开发评估，不是全新盲测或官方 2026 VCC 分数。

原始均值计数的 `log1p` MSE 为真实/随机/无先验 0.075288/0.064272/0.078352，使用参照 NTC 原始均值的基线为 0.009293。这不是归一化响应 MSE；该检查显示负结果也出现在原始计数均值尺度，不能仅归因于 CP10K 组成归一化。

On-target 单独记录。靶基因 readout 可观测的任务数，H1/K562/RPE1/HepG2/Jurkat 为 297/297、6,996/8,989、1,246/1,452、879/955、1,450/1,630。仅在这些任务上，补充计算预测与观测靶基因均值计数的 `log1p` MAE（先背景等权、再三种子平均），真实/随机/无先验为 0.237274/0.233344/0.256904。它是事后描述，未用于选模，不与排除靶基因的主指标混合；未测量的靶基因不补造真值。

## 已核实的限制

- 基础生成校准不足。seed 17 选中 H1 模型的无干预条件均值总计数，相对特征 NTC 的 batch 中位比为真实/随机/无先验 1.767/1.763/2.523。该诊断每个混合分量采样 16 次、四分量加权，不等于主指标的逐细胞 log 均值；不能只把失败解释为生物知识无效。
- 有限采样不足以解释全部差距。早期对 H1、K562 各按固定哈希取前 128 个相同靶点，有限样本 NTC MSE 为 0.003249/0.004623，数学零响应为 0.002718/0.002723，真实先验为 0.015469/0.037848。这是两批任务的事后诊断，不与全任务均值混用；现已用上表全任务有限样本基线补充验证，历史结果保持原口径。
- 原 `target_seen_in_training` 指候选训练集合。seed 17 真实先验的 RPE1 折选中第 1 轮时，只实际采样过 K562 的 684/7,185 个合格训练靶点；523 个 RPE1 测试靶点属于候选训练集合却未参与该 checkpoint 的优化。已精确重放采样队列/RNG 核实。最终比较新增 `actually_sampled_at_selected_checkpoint` 并分别分层，不改写历史字段。
- 非保留合格靶点按既定层权重计算，每组 16 次有放回抽样的期望不同细胞数，H1/K562/RPE1/HepG2/Jurkat 为 2.554/1.077/2.010/1.865/2.060。它不是完整 run 累计细胞数或生物重复数。H1 使用原始完整层的对应期望为 10.503，缓存显著降低层内多样性；K562 原始层也稀疏，对应期望仅 1.423。不能把重复抽样当新增证据。
- Batch 匹配与平衡定义了估计对象，不能分离与背景重合的平台、时间、效应器和培养条件。低支持层协方差、NTC 推定状态和模块 RNA 支持都不是机制 ground truth。PCA 指标只覆盖投影空间；缺少独立生物重复标签，种子和靶点 bootstrap 不能替代它们。

最少八轮限制的是外折停止时刻，未限制 best checkpoint 的候选轮次，故可以最终使用第一轮模型。最终拟合又直接采用外折 best 轮数中位数（1–6），没有单独检查覆盖或 KL 预热。每轮固定 512 步、每步四个靶点，按背景平衡时，每背景平均抽样由三个训练背景时的约 683 次降为五背景时的约 410 次，降低约 40%；相同轮数不代表相同训练暴露。K562 的 7,185 个合格靶点在最终拟合中约需 18 轮才能首次覆盖，这只是一次覆盖门槛，不是收敛保证。

还有一项实现风险：`construct_model` 用候选训练池定义 `seen`，不是 best checkpoint 前的实际靶点暴露；seed17 完整模型有 1,007 个外测任务的靶点在候选池内却未实际采样，仍启用了没有该靶点数据梯度训练的 embedding。该问题在此只记录，未改写模型或历史预测。

上述训练损失来自变化的随机批次，不能据末段下降就证明固定训练目标未收敛；跨背景验证恶化也不能证明继续训练一定改善泛化。目前能够确认覆盖和预热不足，无法证明优化已充分收敛，也无法把主要失败原因单独归给架构或训练。按既定轮数/早停完成仍是历史执行事实，但不满足“所有交付模型已获得充分训练”的结论。
