# C-MECHANISM-PORTFOLIO：组成 logFC 与模板计数校准整包

比较、三路线资源配额、共同数据/官方评分和结束判据见[共同方案](../response-transport/PLAN.md)。节点 `composition-lfc-s01`，证据 `E-MECHANISM-PORTFOLIO`。本路线联动任务与生成器，先完整评价价值，不要求线性头预先获胜。

从相同允许原始细胞重算每细胞 CP10k 的算术均值及方差。训练细胞数、标签、测量位置及重新累计的 float32 平均 logCPM 必须与冻结输入完全相等；H1 只读 input NTC，因重新分块允许 float32 精度的 log 均值误差。原始文件全哈希、读取前后身份验证；矩统计写入本 run/cache/moments。

每来源的响应是 `log((μpert+0.1)/(μNTC+0.1))`，仅在实测位置按扰动细胞数/100 聚合。这是该响应空间的加权平方损失解析均值。目标组成取 `max((μtargetNTC+0.1)*exp(response)-0.1,0)` 后归一；source 缺测不进分母，无来源响应为零。加性 pseudocount 允许 target NTC 零基因被激活，其跨背景可迁移性是待检验假设。

生成按相同 seed+target_index 抽取 400 个 NTC 模板和文库。初始每细胞概率是 99% 模板组成 + 1% 预测组成；64 次列缩放到 n×目标概率、行缩放到 1，最后乘各自文库随机取整。它匹配平均细胞组成，不是对 pooled counts 的比例校准。保存有限迭代的期望组成 L1 误差和取整后实际误差；不声称有限迭代或取整精确匹配。此前 exp005 等有 IPF 代码，本实现改变的是约束空间；不借用其历史评分。

训练结束为全部允许原始细胞的统计和全部掩码下的解析响应拟合完成，无超参数搜索。两个正式官方面板完整评分后才形成整包证据。模型 checkpoint 为包含完整解析状态、掩码、响应和配置哈希的 NPZ；恢复核验状态。采用共同 +.02/−.02 信号门槛；有价值再追加跨背景确认和 T/I 拆分。

启动：`./reproduce.sh --run-id composition-lfc-s01`，同条件恢复加 `--resume`。独立 uv 环境，登记并冻结共用 provider 代码，所有产物归本 run。
