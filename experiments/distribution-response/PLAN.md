# C-MECHANISM-PORTFOLIO：均值—离散度联合分布整包

比较、三路线资源配额、共同数据/官方评分和结束判据见[共同方案](../response-transport/PLAN.md)。节点 `distribution-nb-s01`，证据 `E-MECHANISM-PORTFOLIO`。本路线联动 T/A/L/I，不以拆分消融作为本轮准入条件。

独立重算完全相同允许细胞的 CP10k 算术一阶、二阶矩及平均逆文库，逐背景保留测量掩码。输入匹配与原 log 均值校验和组成路线相同。该拟合使用矩估计和有限样本收缩，**不是 NB 最大似然训练**。

均值响应为 μpert−μNTC，逐实测来源按扰动细胞数/100 聚合；目标均值为 max(μtargetNTC+response,0)，归一到 CP10k。方差按 n−1 无偏估计，额外 Poisson 离散度为 `max(varCPM-μCPM*10000*E[1/library],0)/μCPM²`，均值零取零，截断到 [0,10]。扰动 φ 按 n/(n+50) 向来源 NTC 收缩；n=1 完全回退 NTC。传播 `log((φpert+.001)/(φNTC+.001))` 的掩码加权均值，目标解码后截断 [0,10]。公式中的独立文库/组内平稳假设可能不成立，需要检验。

以相同流抽取 400 个目标 NTC 文库 L，基因期望为 L×预测组成；φ>1e−8 时采样 Gamma(shape=1/φ,scale=expected×φ) 的 rate，再采样 Poisson。φ 很小时直接 Poisson。文库只在期望上保持，非精确细胞总量；输出仍满足官方非负整数及每细胞总量限制。条件基因独立可能破坏相关性；NTC 零响应诊断与六分项需明确这一代价。

结束条件为完整矩拟合、解析参数 checkpoint、全部生成与两个官方面板评分。不得用统计完成或 smoke 代替结果。采用共同 +.02/−.02 信号门槛，成功后才为均值任务、离散度与采样拆分预算；失败不推断其他 NB 神经似然模型无效。

启动：`./reproduce.sh --run-id distribution-nb-s01`，同条件恢复加 `--resume`。独立 uv 环境；本轮与组成路线分别重算原始矩，避免动态未知来源改变预先冻结配置。
