# exp00701：跨 context 响应特征实验结果

三组新增 runs 均已完成 512 轮训练、七个 H1 检查点评估和模型 Artifact 上传。历史 exp007 对照直接引用固定结果，未重训或改写。训练代码提交为 `322aeabf0e4841ec4887f4ed983774775cac664a`。

## 结论

本次最好的新增特征组是 **连续响应**。仅加入其他训练背景同靶点的连续 log2FC 统计，H1 Overall 从 0.02042 提高到 0.12717；在此基础上加入 DEG 汇总证据未带来增益。三个新组都没有超过固定 shared-response 基线（0.18677；zero 基线 −0.06262）。因此实测响应迁移有价值，但本实现尚未解决 H1 的全部任务短板。

| 特征组 | 维数 | 最佳轮数 | 最佳 H1 Overall | 固定 512 轮 Overall | 512 轮训练 RMSE |
|---|---|---|---|---|---|
| exp007 历史对照 | 70 | 512 | 0.02042 | 0.02042 | 0.59263 |
| 连续响应 | 77 | 128 | 0.12717 | 0.12290 | 0.58490 |
| + DEG 证据 | 87 | 128 | 0.11078 | 0.10095 | 0.58378 |
| + 响应模块 | 169 | 128 | 0.10401 | 0.10153 | 0.58058 |

所有组均使用相同 seed=17、四个训练背景、训练样本、平方误差目标、eta=0.05、depth=6、512 轮预算、预测生成器和 H1 评分口径。只有输入特征组发生变化。新增特征降低训练误差，却未按特征数量单调改善留出表现。

模块组相对 DEG 组：最佳分数低 0.00678，固定 512 轮则略高 0.00058；不能将模块的影响概括为稳定变差或稳定改进。两种口径下，DEG 与模块组均没有超过仅加连续响应的方案。

## 数据与泄漏边界

K562、RPE1、HepG2、Jurkat 训练；H1 是唯一开发验证 context，并用于选择检查点。没有完整五折、五背景最终拟合或榜单提交。H1 共 297 个靶点，其中 269 个在训练背景出现，28 个未出现。此处 Overall 是本地 H1 面板归一化分数，不能等同于官方榜单分数。

每个训练样本的响应特征排除其自身 context；H1 响应永远不进入输入。连续幅度使用全部合格来源细胞的 CPM 算术均值 log2FC；DE 证据使用固定至多 400 个扰动细胞、全部 NTC、NTC CPM>5、每扰动 BH<0.05，并排除靶基因自身。缺测保留来源支持数，非显著不解释为零效应。

模块组使用 16 维固定 Reactome SVD 坐标编码来源上调/下调列表，附加列表大小、读出基因坐标及其交互。坐标不由响应标签拟合。这是当前固定通路表示的消融，不能概括所有 DEG 编码器；该组同时加入读出基因坐标，未单独消融其静态信息贡献。

DEG 与模块组的 HepG2、Jurkat、K562、RPE1 四份证据缓存 SHA-256 完全一致，包括独立重算的 RPE1。模块坐标 SHA-256 为 `d6cf01ff3ece9cb4be51a10e0306ef44ece02b734e74c0a455c3204589babc08`。源数据的固定引用见 `configs/source-reference.json`，每次启动重新校验；scorer 可写缓存为本 run 私有副本。

## 局限与下一步

1. 这次结果支持保留连续响应作为后续对照；不支持把本次 DEG 汇总和固定通路模块直接作为改进版。应优先研究来源 context 的适配、方向置信度和幅度校准，再以相同留出比较。未在本任务额外启动这些研究。
2. 来源背景只有四个，靶点覆盖、细胞数、DE 检验功效不同；训练接收 context 最多使用其余三个背景，H1 可使用四个。未检出与缺测均不等于无生物学效应。
3. 延用原生成器是控制变量；早期检查点的 scorer 曾提示伪 bulk 跨扰动变化相对于采样修正偏小。评分使用固定版本的有界修正，不通过更换生成器解释本次特征收益；本实验没有验证更真实的细胞分布生成。
4. H1 被反复用于开发与选轮数。尚需新的独立 context 或预先冻结的测试集确认泛化，不能据此宣称跨 context 普适改善。
