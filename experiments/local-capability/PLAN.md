# 本地评价器能力验收

Comparison: `C-LOCAL-CAPABILITY-EVALUATOR`。这是固定计数对照的评价器验收，无预测器拟合。完成不代表任何模型已通过 LOCO 或 joint-OOD。

KnowGraph attention: `EXP-LOCAL-EVAL`, `EXP-LOCO`, `PAP-F-PATHWAY`, `ST-WILCOXON`, `MY-YBD`。只把图谱用作评分范围、模板与通路诊断的注意力提示。

## 冻结范围

复用 task-observation 成功 run 的哈希固定观测视图，在五背景各执行 S2、S3 和对应 S4 面板，共 15 个背景×划分面板，每面板 16 个按身份哈希选择的结构合格靶点。稀缺真实细胞不复制；每靶最多 400 个真实细胞；评分 NTC 与输入 NTC 物理不相交。只在每背景真实测得的官方子轴评分，完整轴覆盖和真实 n 单列。此处遍历分割仅检验数据和评分路径，不能代替每个外层划分的独立预测器训练。

每面板重建冻结 `cell-eval2` commit 的 `vcc2026` baseline、real-bundle 和五次 anchors。评分接口和公式复用官方实现。记录六项 raw、normalized、Overall、逐靶 DE、有效数和退化原因；不能靠删指标、扩大细胞数、挑强响应或借用别的 panel anchors 使评分可用。因中断残留的 bundle 原样保留，新同条件 attempt 另建目录。

## 四种固定对照

1. `real_copy`：复制真实整数计数，明确为不可部署的 oracle 正对照。
2. `target_derangement`：相同真实矩阵仅将全部扰动标签按预定循环置乱，无固定点；保留源群体的真实 n。
3. `zero`：每靶从独立输入 NTC 抽 400 个细胞，零响应生成。
4. `oracle_template`：固定半数靶点的真实 bulk 响应均值给出评价器侧模板；基于输入 NTC，使用已登记计数生成器每靶生成 400 细胞。此 oracle 还使用评分 NTC 将模板定位到真实基线，不能作为模型输入。

模板估计靶点由身份哈希固定为半面板，另半面板用于响应/残差/通路诊断；官方六项仍评分完整 16 靶面板。投影移除模板方向，不能仅减均值。诊断特征排除完整 panel 的靶点，固定 Reactome GMT 哈希、至少 5 个实测成员，报告覆盖、无效相关性和有效靶数。通路重叠不作为独立重复。

## 预定判据和完整预算

每面板 6 项验收：输入与参考物理不相交；oracle 原始响应及去模板残差 RMS 误差各 ≤1e-10；置乱后平均响应 RMS 误差 >1e-4；四对照官方六项及 Overall 全部有定义；oracle 相对置乱的 raw PDS 差 >0.01。共 90 项，全部通过只支持评价器接口与标签敏感性。模板残差幅度、DE 精确率/漏检、通路恢复和原始/归一化分数全部另报，不将模板对照成绩称为预测能力。

单个 seed 930，无超参搜索：15 个新官方 bundle、60 次完整官方评分、60 份响应/通路诊断及对应 DE 表、计数文件、artifact；完整执行至全部 15 面板结束，预计主要为数小时以内的 GPU 评分和磁盘 I/O。技术失败恢复同条件阶段；科学条件更改新 run。未定义 anchor 完整记录，按验收失败处理，不伪造 Overall。

源观测诊断未通过时仍允许完成评价器验收以定位限制；但不得把失真的生成器自动晋级为部署默认。后续 DepMap 每个实际独立拟合另立 run，先冻结数据、对照、生成器和完整预算。本验收不执行 leaderboard 提交。

## 根据观测批次增加的细胞数敏感性诊断

在本验收 run 冻结和执行之前，观测批次的 K562 对照显示真实 n 较小而生成 n=400 的 DE 集合明显不同。因此每背景另加一次官方 DE 调用：复用观测批次 4 个固定靶点的既有真实矩阵及守恒生成矩阵；保持生成的 400 细胞总体不变，按真实 n 做 5 次无放回抽样，与完整 400 细胞和真实群体比较显著基因数。参考 NTC 沿用原校准的相同半池。

这 5 次附加调用只诊断固定总体下的细胞数敏感性，不重新生成响应、不补足真实 n、不改变正式预测 400 细胞要求，也不构成生物重复或全部分布误差的归因。所有抽样行号、来源哈希和官方 DE 表保存。此项不事后修改原观测 run 的 20 项检查，也不计入评价器预定的 90 项接口验收。
