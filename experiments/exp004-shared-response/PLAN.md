# exp004：共享读出与状态条件化响应

需求与执行进度由 [Issue #35](https://github.com/yjcyxky/virtual-cell-challenge/issues/35) 管理。用户于 2026-09-25 授权完整实现并启动训练、消融；exp003 原工作区及活动 run 保持不变。此分支只复用其数据、训练、评估流程，通过显式模型和目标接口接入 exp004。正式训练代码及锁文件先提交，运行不修改源码或环境。

## 问题、数据与边界

给定背景 NTC 与 CRISPRi 靶点，学习统一归一化尺度上的扰动响应，同时生成扰动后整数计数细胞。检验共享生物学表示能否改善无直接表达监督 readout 的迁移，非可分离关系变化能否改善跨背景预测，以及幅度、靶点特异性目标是否提供额外收益。不能把注释或观测关联称为 ground truth 因果边。

沿用 exp003 的五个数据集 H1、K562 GWPS、RPE1、HepG2、Jurkat；每折其余四个完整合格数据集训练、留出一个完整背景验证。共五折，不建立第六个全背景模型。H1 三个 2025 面板属于同一背景，2026 leaderboard 是独立最终测试，本矩阵不提交。已登记输入只读，复用 `20260923-mcvae-true-s17/cache/data` 固定计数缓存并校验其数据条件、文件摘要。每靶点最多 128 缓存细胞、每技术层每半池最多 64 NTC 的既有取样约定不变；“完整训练”指缓存内全部合格任务，而非所有原始细胞。

固定 18,533 输出基因；未测量基因显式掩码，主响应目标使用五背景共同可靠测量的 6,114 基因，NB 可利用各训练背景额外测量基因。按背景→靶点→构件→batch 平衡，双 guide 是一个构件；NTC 特征半池和参照半池固定独立。只用四训练背景拟合 PCA、潜状态、损失尺度与先验置信度，验证背景仅允许使用 NTC 特征。验证扰动数据只用于评价、选模及早停。五背景均已用于项目开发，结果是开发验证，不能当作新独立测试。

## 模型

保留条件混合潜变量 CVAE、状态共享引起的联合依赖、NB 计数分布、缺测掩码、基因激活项、直接 on-target 分支及背景 NTC 输入。不是独立的任意标量平移模型，也不声称恢复全因果基因网络。

共享读出：用公共注释构造固定基因特征：功能网络谱基、物理网络扩散、完整 Reactome 成员的 32 维随机投影、完整 GO 正向成员的 32 维稳定 signed hash、96 个所选模块成员。GO 只接收当前基因轴精确 symbol，排除 NOT；未映射注释不补成假标签。各列 RMS 标准化并截断至 ±5，模块列再乘训练 NTC 内 batch 去均值后的候选减随机关联置信度，最低权重 0.25，未观察到不直接判假。投影与特征哈希固定并保存。

64 维共享 MLP 将特征映射为模块、残差、离散度和 gene gate 的读出参数，删除这些分支的自由逐基因参数行。由训练基因的梯度共同更新未监督基因使用的映射，但不保证后者生物学预测正确。保留似然后验编码器的逐基因权重及已见靶点 embedding；这些不作为未监督基因的自由生成读出。shared_target 进一步用相同特征映射生成靶点表示，与已见靶点 embedding、NTC 中靶点表达和测量标记共同条件化模型。

新增关系算子 `A(s) = W(features) + U(features) diag(g(s)) Vᵀ`，rank=8，`g` 输入 NTC 背景摘要与潜状态，屏蔽靶点专属条件两个字段。它可改变 2×2 交叉比，不局限于原模型的行列缩放；原可分离 gate 保留为共同结构。g 零初始化，经梯度学习。固定关系对照把 g 输入置零，仅学习常数；关闭对照仅用 W。参数分配相近，但关闭/常数对照的有效自由度不同，不能声称严格容量相等。

真实先验对照使用注释。random_prior 对完整特征在功能度数 log2 分箱、GO/Reactome 可用性分层内置换基因行；所选 target_prior 模块另沿用保持模块大小和每族基因度数的双边交换空模型。两个随机操作不是同一网络重连；整套 random_prior 仅检验注释语义破坏后的变化，不把差异独归某条边。no_prior 把基因特征和靶点模块输入置零，检验移除外部信息；它同时使共享 readout 更对称，需结合 random_prior 解读。真实/随机的 NTC 置信度各由其候选模块计算。

## 目标与消融

基础目标完全沿用 exp003 当前配置：主项是预测扰动和预测 NTC 的 `log1p(CP10K(weighted_mean_counts))` 差值，对真实匹配 NTC 响应的标准化、信号加权 Huber；另有 NB ELBO、预测 NTC 锚定及计数深度矩辅助项。聚合、测量轴、batch 权重与参考池不变。

amplitude 只额外加入响应沿真实有符号响应方向的投影比例误差：`Huber(<δhat,δ>_w / (<δ,δ>_w + 1e-4), 1)`，乘基于真实响应和标准误的可靠性。它约束正确方向的尺度，在 δhat=0 仍有梯度，不是仅匹配长度。specificity 只额外加入同背景 8 个训练靶点响应的 soft retrieval KL：真实响应之间的正则化 cosine 相似性经温度 0.2 softmax 作为教师，预测响应产生学生分布；排除候选靶点对应基因，近似机制允许软相似，避免强制一热互斥。候选池只含四训练背景标签，噪声由可恢复采样器 RNG 控制。它不是官方 PDS 的直接实现。

主响应系数固定 1；初始生成器梯度校准基础辅助比例 ELBO/NTC/depth=0.1/0.25/0.05。新增单一项比例 0.05，系数截断范围 [1e-6,100]，训练后固定；校准、实际比例与各项梯度保存。总 loss 跨 arm 不同尺度，不以总值大小排名。

| arm | 相邻对照回答的问题 |
|---|---|
| reference | 在新环境和相同配置内复现 exp003 自由 readout 基线 |
| shared_readout | 相对 reference，共享读出是否有效 |
| shared_target | 相对 shared_readout，共享靶点表示是否有效 |
| fixed_relation | 相对 shared_target，固定低秩关系额外容量是否有效 |
| conditional | 相对 fixed_relation，背景/状态依赖关系是否有效 |
| random_prior | 相对 conditional，注释语义是否有价值 |
| no_prior | 相对 conditional，移除外部注释的变化 |
| amplitude | 相对 conditional，单独增加幅度投影目标的收益 |
| specificity | 相对 conditional，单独增加软靶点区分目标的收益 |

每 arm 独立从头训练 seeds=17/29/43，每 run 五折，共 27 runs、135 fits。先运行 conditional，再逐个对照，以 seed 为外层顺序执行；没有同时叠加两个新增损失的 arm，避免本轮无法区分作用。fold 初始化固定且可复现，但新旧架构参数形状/RNG 消耗不同，不宣称初始权重逐项匹配。

## 充分训练、评估与资源

AdamW 固定 LR=0.001、weight decay=0.0001、clip=10，KL 前 2048 步预热，不变学习率。完整覆盖周期定义为四背景所有训练靶点至少进入一次优化，不按最小背景截断。固定训练面板每周期记录，NB 每靶点四个训练权重层样本，响应覆盖全部训练任务。官方验证在覆盖周期 1/4/7 及 10 起每周期进行，三个固定生成种子 101/202/303，使用固定 cell-eval2 0.16.0 commit `5e64833518a6603a0301cbe28185d49c30f4a986` 的完整 vcc2026 六项与本地 real bundle。

从周期 10 建立早停窗口；最近四点跨三完整周期的每训练背景总 loss 与 response_loss 相对范围均 ≤1%，且验证综合分连续三周期累计无 ≥0.001 改善，完成 KL 预热才正常早停，最早周期 13。没有人为最大轮数截断；条件不满足就继续。保存实际最佳 checkpoint 与最后完整状态，任意已评估新高均保留。模型、优化器、scheduler、采样器、Python/NumPy/Torch/CUDA RNG、覆盖与早停状态全恢复。

比较各折三生成种子均值及六分项、三训练种子的配对差异；辅助报告 delta MSE/MAE、零响应/共享响应基线、未监督 readout、seen/unseen target 与 batch 支持层。不得把五折最佳开发分数等同 leaderboard 数值，也不把机制能力测试等同实证收益。若五折或种子结果不一致，如实报告。参考基线同样完整训练；所有 arm 适用相同停止规则，但实际更新次数可不同。

GB10 上本矩阵一次只启动一个 run，CPU 线程 4，与 exp003 共享 GPU；没有尚未测量的时长承诺。异常立即使队列失败并保留状态，不跳过该 run，恢复同一命令继续。27-run 结果汇总写到最后真实 run 的 `matrix-comparison.json`，不建立阶段 run。训练全部结束后再汇总 REPORT 并更新 Issue，不以测试通过或启动成功宣称研究完成。
