## 拟合、覆盖与正确性

四臂均使用 17,040 个背景×靶点训练任务，9,867 个训练靶点；2,541,598 扰动训练细胞不等于独立背景。训练为四背景/两研究，测试是 H1 一个背景；guide/生物重复独立性仍未知。生成112,000细胞/臂、400细胞/靶不增加生物重复。

完整输出18,533基因，H1实测评分 18,074；训练测量并集10,916，H1中有 7,292 个实测基因没有任何训练响应，本轮保持零Δ回退。Reactome覆盖6,832基因，其中 6,757 在H1实测；1,372模块、65,816边，真实/随机逐基因度数和逐模块大小相同。

低秩拟合仅使用 2,387 个在该覆盖轴完全监督的训练靶点 shared 行，未中心化 SVD，rank32、oversample16、power2、seed1729。该群体偏多背景共同研究靶点，是外推限制。没有将缺测零当训练标签、没有读取 H1 扰动响应或用 H1 NTC 拟合表示。
低秩捕获的训练响应能量比例 0.646494；这不是留出预测准确率。随机图完成 658,160 次成功交换 / 751,345 次尝试，原边重叠比例 0.062006。

新 shared 与原 init-linear-s01 的响应逐值相等，112,000 行预测计数全部一致。主/重叠 Overall 复现差为 +0 / +5.55e-17。原zero/shared/source辅助参考经严格哈希及配置/响应核验后复用；本轮shared独立重算、重新生成和评分。

representation 审计中的 training_response_used 指基的学习；所有臂的共享响应及重构均使用允许训练响应。三个候选在99个四背景支持靶点上的39,600行预测计数均与shared一致；这些靶点的补全掩码为空。其余靶点保持已监督Δ，但生成器的文库恢复会把缺测位置变化传到其他基因计数，不能把所有评分变化归因于被补全基因的直接生物准确性。

## 决策与限制

保留shared零回退；暂不采用本轮三个rank32补全候选，不继续在H1搜索秩/正则。下一优先问题为Q-QUALITY/C-SHARED-QC：基础正确性数据、额外质量筛选、匹配随机删减，以固定评估群体分离可靠性与数据量/覆盖变化。

下一比较沿用当前强 shared 控制，并登记两个新的 draft 候选；初始化的旧 C-QC/条件 ridge 草案继续保留，不直接作为本轮决策的执行入口。质量规则、数量/覆盖匹配、统计重算、完整配置和数值判据仍须冻结后才能启动，不能把本轮结果当作 QC 已有效的证据。

单背景、单训练/生成seed，只能支持当前实现与范围的开发决定；靶点不是独立背景。未做五背景轮换、研究留出、全局未见靶点或本轮新官方提交；无法声称SOTA。随机对照仍保留基因覆盖/度数等边际信息，仅识别成员关系超出这些边际的价值。Reactome先验不是留出准确性的保证，低秩完整行也不覆盖所有靶点分布。新增监督/表示来源或外推范围改变时以新比较重开，保留本结果。
