## 1. 对 idea 的理解与本轮要回答的问题

核心假设是：**目标细胞的未扰动状态，既影响扰动引起的功能模块响应，也影响模块响应如何落到具体基因；基因特异性残差负责保留模块无法表达的细节。**最终模型可以写成：

\[
\widehat\Delta_{p,c,g}
=\sum_k W_{gk}(h_c)z_k(e_p,h_c)+r(e_p,e_g,h_c).
\]

这里的创新假设是背景依赖的共享结构，而非把模块均值按表达比例分配回基因。模块均值不能唯一确定模块内各基因的变化方向。

本轮首先建立上式中基因分支的参照：

\[
\widehat\Delta_{p,c,g}=f_\theta(e_p,e_g,\phi_{p,g},h_c,a_{p,c},a_{g,c}).
\]

`p` 是 CRISPRi 靶基因，`c` 是明确培养/刺激条件下的背景状态，`g` 是输出基因；`h_c` 和 `a` 只来自该状态下未接受目标 CRISPRi 的匹配 NTC。NTC 可以处于相同药物或刺激条件，不能据此称为完全未处理细胞。这个基线将来可以作为模块模型的残差分支，也可以独立作为必须超越的比较对象。

**本轮检验 H1：在整个细胞背景未参与训练时，加入该背景的未扰动表达信息，是否比相同基因关系特征的静态成对模型更准确？**

同时检验基线是否优于零效应和简单效应迁移。此轮成功只支持“细胞状态对基因级预测有用”，不能证明功能模块有效。真实模块、随机模块、低秩结构和背景条件化模块的比较留给后续独立实验。

首轮不训练基础模型、不引入 ESM-2/SE-600M 表示、不整合 Hi-C、不使用 DepMap 扰动必需性标签辨认目标细胞、不把模块伪装成基因 token。这样可以清楚识别背景信息本身的贡献。已有 ESM 权重不等于已有按基因对齐的蛋白表示，后续加入时还需要冻结序列与映射版本。

### 3.2 元数据、去重与两层资格

标准记录至少包含 `source_id, study_id, sample_id, physical_context_id, leakage_group_id, context_state_id, condition_id, dose, timepoint, batch_id, guide_id, cell_id, target_gene_id, is_control, perturbation_type, modality, counts_layer, gene_mask_id`，并链接原始记录。缺失字段显式为 unknown；不凭字段名猜测 raw counts 或 guide 语义。

- `physical_context_id` 描述真实细胞背景；`context_state_id` 同时保留培养、刺激、药物剂量和时间，本计划公式中的 `c` 指该状态。不能把条件不同的样本直接合并。
- `leakage_group_id` 合并同一物理背景的所有来源、副本、批次和条件；已知同源/衍生关系需核验并保守分组。模型不使用这些 ID 作为特征。匹配 NTC 必须来自相同物理背景、条件、剂量、时间和可比批次。
- 单构件内多个 guide 指向同一基因仍可属于单基因 CRISPRi；组合靶基因、doublet、歧义标签和 CRISPRa 不转成合格监督。条件性 CRISPRi 可接纳，药物单独扰动不改名为 CRISPRi。
- 优先保留来源已发布且语义明确的细胞 QC；补充检查计数有限、非负、整数、非零文库、基因映射和稳定身份。不得按测试效应、靶基因残留表达或 DE 数量筛选任务。
- 去重结合研究/样本/文库身份、原始 barcode、批次和计数核对。H1 重复 NTC 仅保留一份；同 barcode 但计数或标签不同必须解释。不同研究的相同 barcode 不自动删除；相同研究的不同 accession 也不自动当作独立证据。

**语料资格与实验资格分开。** 语义可靠的 80 细胞任务可以入库；控制池不足本实验阈值的来源也保留真实数量及限制，不为满足 Exp001 删除共享观测。`representation_only` 数据不增加监督任务数或匹配 NTC 数。

Exp001 读取冻结语料后建立专用视图，沿用以下数量默认值：

1. 每个 `(context_state, target)` 至少 100 个合格扰动细胞；不满足的任务留在语料及覆盖报告，不进入本轮监督/主评估。
2. 控制按条件内的匹配批次，以固定哈希排序平衡分成 `C_feat`、`C_ref`；每个状态两池各至少 400 个细胞，每个参与配对的批次两池各至少 50 个。两池不共享物理细胞，所有模型使用同一切分。
3. `C_feat` 用于特征、重建和生成深度，`C_ref` 用于独立 DE/官方实现评估。外部表示数据不能补齐任一池。报告被排除批次、任务数及原因。
4. 主测试分层 30 个、严格测试分层 20 个是研究结论的样本量门槛，按 §2.3 处理不足；不是语料入库或有有效任务时继续运行的门槛。

### 3.3 基因轴和未测量值

共享语料保留来源测量轴、标准基因 ID、映射审计和未测量掩码，不为 Exp001 预先丢弃轴外基因。Exp001 的正式轴记为 `G`，各背景状态实际测量且无歧义映射的基因集合记为 `M_c`。同一基因的重复列仅在证明是可相加的计数来源后合并；一对多别名不随意选一个。映射过程输出逐基因审计表。

**未被测量与测量后为零必须分开。**未测量基因不产生监督标签，不进入该背景的损失；缺失特征使用 NaN 和显式掩码。不能把未测量列填零后当作“无响应”的训练样本。

每折记录训练可监督基因集合 `M_train`。主评估基因集合为 `E_c = M_c ∩ M_train ∩ G`，排除当前扰动靶基因；同一任务的所有模型共享此集合。补充报告所有背景共同测量基因上的指标，以及目标背景全测量集合上的指标，后者包含训练不支持基因的保守回退。逐项公布分母、覆盖率和回退比例。

训练不支持的输出基因预测零变化并标记 `unsupported`；**对已测量但控制中为零的基因不施加零变化硬规则**。正式目标背景缺少要求的测量轴时停止格式导出，不通过伪造列满足格式。

### 3.4 深度与伪批量

共享语料保留原始计数；以下 thinning 和聚合仅写入当前 run。本轮采用 20,000 UMI 的**设计上限**，作为已有 H1 数据档案建议的深度敏感性控制；它不是已核实的官方评分器默认值，也不等于把所有细胞都变成恰好 20,000 UMI。

- 在完整原始测量轴上，对高于上限的细胞以 `Binomial(x_ig, 20000 / L_i)` 做独立 thinning；低于上限的细胞保持原计数，不上采样真实细胞。结果仍是整数，20,000 是高深度细胞的期望总量。
- thinning 种子由全局种子和稳定 cell ID 派生，避免读取顺序改变结果。预测、真实和对照的深度策略一致，固定数据种子不随模型 seed 改动。
- 基因映射后，按批次和 `(c,p)` 流式聚合；对照采用匹配批次的 `C_feat`。只保留计数和、细胞数、检测计数等充分统计量，不复制整个原始稠密矩阵。
- 每个任务先形成各批次的归一化伪批量，再按该扰动在合格批次中的细胞比例聚合；相同权重用于匹配对照。批次权重仅在训练标签构建或评估侧使用，不作为推理必须输入。模型特征始终来自该背景完整 `C_feat`。
- 降采样不会消除平台、测量基因面板、培养条件或低深度的差异。报告每个背景的映射覆盖和 thinning 前后深度；跨研究留出同时包含平台迁移，不能把效果全部解释为生物背景迁移。

### 4.1 外层留出整个物理背景

|---|---|---|---|

### 4.2 靶基因也未见的严格子集

对标准 HGNC ID 计算 `int(sha256("exp001-target-v1|" + id), 16) % 100`，所有来源和背景使用相同分组：

- `0–79`：训练候选靶基因，仅实际入选的训练背景标签进入拟合。
- `80–89`：内部验证专用的新靶基因，允许用于选择，因此不称为最终未见靶基因。
- `90–99`：严格测试靶基因；**三折评估阶段**在所有背景中的这些标签均禁止进入训练、早停、校准和模型组选择。最终重训是否释放这些公开标签由 Q16 决定，不追溯改变三折评估口径。

RPE1 使用前两组，分别计算任务宏平均后等权聚合，防止较大分层主导选择。某分层无有效任务时，预定选择指标不可用，应报告并解决，不静默改成另一个指标。

| 分层 | 定义 | 解释 |
|---|---|---|
| `context_unseen_target_seen` | 背景未见，靶基因实际在本折训练中出现 | 跨背景迁移，主终点；少于 30 个任务时描述性报告 |
| `context_unseen_target_unseen` | 背景未见，靶基因属于 `90–99` | 双重未见，独立次要终点；少于 20 个任务时描述性报告 |
| `tuning_seen_or_other` | 验证见过，或自然缺失形成的其他组合 | 补充描述，不混入前两组 |

严格未见仍可使用靶基因的静态 STRING 信息及目标 NTC 表达；“未见”指扰动响应标签未被用于拟合和选择。公布实际已见靶基因，而不是把哈希落在 `0–79` 的全部基因都称为训练已见。

### 4.3 数据量上限和封存

语料保留全部合格记录；Exp001 视图每个物理训练背景最多选 800 个训练候选靶基因，其不同条件共用该靶基因清单。验证和测试各分层最多 150 个靶基因，均在资格检查后按固定哈希排序选取，不依赖效应，也不要求所有背景同时覆盖。冻结各状态的实际任务数；条件增多带来的行数和资源开销需重新估算。

当前 run 保存物理背景/泄漏分组、条件、细胞分池、候选及排除理由、训练靶基因清单、评估面板和监督掩码。训练进程只读取训练标签及验证接口，测试效应聚合与指标仅由封存后的评估流程读取。语料入库阶段可核查计数、标签语义、重复和数量，但不将测试响应摘要用于拟合或选择。除允许的目标 `C_feat` 外，标签摘要、DE 表及噪声地板均继承其 train/validation/test 角色。

## 5. 标签、特征与模型

### 5.1 预测尺度

对一组原始计数先求和，再在其已测量且映射成功的基因轴上归一化：

\[
\mu_{u,g}=10^4\frac{\sum_{i\in u}x_{ig}}
 {\sum_{g'\in M_c\cap G}\sum_{i\in u}x_{ig'}},\qquad
b_{u,g}=\log(1+\mu_{u,g}).
\]

根据第 3.4 节先批次配对聚合 `μ` 后再取 `log1p`，定义监督标签：

\[
\Delta_{p,c,g}=b_{p,c,g}-b^{\mathrm{matched\ C\_feat}}_{p,c,g}.
\]

它是**归一化伪批量的自然对数 log1p 差**，不是 log2 fold change，也不是单细胞先取 log 再平均。训练不把任意正负残差直接当 raw counts。不同基因面板导致分母不同是此轮局限，共同测量基因的敏感性评估用于检查该影响。

推理以目标完整 `C_feat` 的 `b^0_c` 重建：

\[
v_{p,c,g}=\max\{0,\exp(b^0_{c,g}+\alpha\widehat\Delta_{p,c,g})-1\},
\quad
\widehat\mu_{p,c,g}=10^4v_{p,c,g}/\sum_{g'}v_{p,c,g'}.
\]

本地重建的求和范围为该背景的 `M_c ∩ G`，未测量位置保持掩码，不能让 NaN 进入指数或把未知表达算入分母；本地计数评估文件使用这份实际测量轴。正式目标数据轴完整时范围才是全 `G`。

在计算指数前将重建 log 表达限制在 `[0, log(1+10^4)]`，记录命中比例；归一化总量为零则标记预测失败。所有模型使用相同重建规则，记录裁剪/归一化前后误差。这个组合约束意味着最终效果应在重建后评估，不能只挑回归器的原始残差指标。

### 5.2 特征定义

| 特征组 | 精确定义与准备方式 | 可使用的信息 |
|---|---|---|
| `e_p, e_g` | STRING combined score ≥ 700 的无向稀疏图，权重除以 1000；HGNC 映射后多蛋白边取最大值。对称度归一化邻接矩阵，TruncatedSVD 32 维，seed=17；保存变换与符号约定 | 固定外部先验，可含未见靶基因；无扰动标签 |
| 成对关系 `φ` | 直接 STRING 分数、是否有边、邻居 Jaccard、两端 log1p 加权度、表示余弦、32 维表示逐元素积 | 同一固定图 |
| 局部背景 `a_p,a_g` | `C_feat` 的 log1p 伪批量、检测率、单细胞归一化表达方差，以及测量缺失/图缺失指示 | 当前背景的 NTC |
| 全局背景 `h_c` | 训练 NTC 上拟合的 16 维 PCA；每个背景投影后的均值和标准差，共 32 维 | PCA 拟合仅本折训练 NTC；目标只做 transform |

PCA 使用训练背景共同测量、按训练控制均值确定的前 2,000 个非恒定基因，每个物理训练背景按稳定哈希最多抽 5,000 个 `C_feat` 细胞，各条件平衡分配名额。用归一化后 `log1p` 单细胞表达拟合，保存中心、载荷和特征顺序；目标缺失的 PCA 输入用训练中心填充，并报告缺失比例，超过 20% 则该折资格检查失败。PCA 不是功能模块，也不参与输出基因共享解码。

孤立图节点的表示置零并附缺失指示，绝不能丢弃对应预测基因。无向 STRING 只提供关联结构，不规定扰动方向。模型不输入细胞系名称、source ID、guide ID 或随机编码的基因序号；基因身份通过可迁移的表示与表达特征体现。

### 5.3 模型组与控制变量

| ID | 定义 | 作用 |
|---|---|---|
| `B0_zero` | 所有基因 `Δ=0`，重建目标 NTC 基线 | 无扰动效应参照 |
| `B1_gene_mean` | 各状态先对扰动等权平均 `Δ_g`，再在物理背景内对状态、物理背景间分别等权平均 | 泛化响应参照，不区分靶基因 |
| `B2_target_mean` | 对相同 `p` 的 `Δ_{p,g}` 先在物理背景内对合格状态等权平均，再对背景等权平均；无同靶基因/基因覆盖时回退 B1，再无支持则 B0 | 最简单的同扰动迁移 |
| `M0_static_pair` | XGBoost，只用静态图表示和成对关系 | 去掉背景状态的消融 |
| `M1_context_pair` | XGBoost，使用全部特征 | 本轮首个主模型 |

所有组使用相同输入版本、任务切分、训练任务上限、监督掩码、重建与采样器、评估面板和数据随机种子。B1/B2 的每折统计量只由该折训练标签生成，不能调用利用评估真实扰动均值的 oracle baseline。M0 也使用目标 NTC 做最终重建；M1 的增量是**根据背景改变预测效应**，不是独占对照表达。

上面是待落地配置的核心部分。执行前必须展开成完整的实际配置，补齐输入、映射、特征、split、模型、评估器、路径与资源限制；禁止在源码中保留未记录的实验默认值。

- 每个 `(c,p)` 从有效非靶输出基因中固定均匀、不放回抽取最多 1,024 个，M0/M1 共用索引。均匀抽样估计全基因风险，不按训练/验证 DE 挑基因；验证和测试预测全有效轴。
- 扩展条件性语料后，权重按物理背景 → 背景内状态 → 状态内任务 → 任务内抽样基因逐层等权，再缩放到训练行平均权重为 1，使 `min_child_weight` 的数值有明确含义。B1/B2 使用对应的分层平均，缺失支持时仅在有效项上归一化。这样单一背景的多个刺激或来源副本不会使其总权重膨胀；单状态时退化为原规则。百万个基因对不是百万个独立扰动实验。
- 用 RPE1 两种验证靶基因分层的重建 MAE 等权均值早停，校准时另取同样的任务级指标。通过自定义回调每 25 棵树计算一次完整验证指标，连续 3 次无改善停止并取已保存的最佳轮次；不能用 XGBoost 默认的逐行 RMSE 代替任务宏平均。训练目标为平方误差，选择指标为重建 MAE；两者同时记录。
- 每个模型 seed 在 `α=1` 下早停；随后仅在内部验证上选一个全局 `α`，同分选择较小者。不得对测试背景或每个靶基因分别拟合 `α`。报告校准前后结果；B1/B2 也采用相同验证校准规则。
- 不做额外超参数网格或测试反馈调参。三折评估保留 3 折 × 2 个训练模型 × 3 个种子，共 **18 次正式拟合**，并完成 B0/B1/B2 的统计构建与评估。保存各 seed 结果；主预测为各 seed 校准后效应的平均，再执行统一重建。三种子组合方式在看测试前固定。最终重训是另外的 run，不计入这 18 次，也不能替代任何一折。

## 6. 从均值到计数的最小输出接口

首轮主要检验均值预测。为了走通单细胞评估接口，所有模型使用同一个**固定多项式计数采样器**：

1. 从目标 `C_feat` 的映射后、thinning 后文库大小中有放回抽取整数 `L_i`；禁止从目标扰动真实细胞取深度。
2. 令 `π_{p,c,g}=μhat_{p,c,g}/10^4`，对每个任务产生 400 个 `Multinomial(L_i, π)` 样本。
3. 用稳定 `(context, target, generation_seed, cell_index)` 派生 RNG。主 seed=101，202/303 只用于预先规定的敏感性检查，不能按测试成绩选 seed。每个 seed 仍是独立的 400 细胞预测，不合并成 1,200 个细胞。
4. 分任务流式写 CSR，清除显式零，检查整数、非负、有限值、行列标签和预测任务完整性。不得生成整个提交的稠密矩阵。

该采样器只表达给定均值与文库深度下的抽样变异，**没有恢复真实的生物过度离散、细胞状态混合或基因协方差**。因此 DE 指标是输出接口和模型间比较的诊断，不是本轮成功的唯一依据。另输出直接重采样 NTC 的零效应诊断，以辨认采样器本身引起的假阳性；它不替换主比较中的统一采样器。

本地 DE 评估优先使用至少 400 个真实细胞的任务：真实细胞无放回抽 400 个，使用同一冻结 `C_ref`。100–399 个真实细胞的任务仍参加伪批量评估，DE 另表标记细胞数不匹配；不能重复真实细胞凑到 400 并声称相同检验功效。

## 7. 评估、统计与判定标准

### 7.1 主指标：重建后任务宏平均误差

对测试任务，以真实扰动伪批量 `b_real` 与重建后的 `b_pred` 比较：

\[
L_{c,p}=|E_{c,p}|^{-1}\sum_{g\in E_{c,p}}
|b^{pred}_{c,p,g}-b^{real}_{c,p,g}|,
\quad
L_c=|P_c|^{-1}\sum_p L_{c,p},\quad L=\tfrac13\sum_c L_c.
\]

`E_{c,p}` 是第 3.3 节的固定集合减去靶基因。减去同一个目标控制基线后，它也等于该尺度的效应 MAE；不能把“预测后表达与控制表达相关很高”当作扰动预测成功。

同时报告 RMSE、相对 B0 的改善、效应余弦/相关、真实效应幅度分层和已见/未见靶基因分层。余弦遇到近零向量时标记未定义并报告数量，不把 NaN 改成完美匹配。MAE 主终点不因真实效应弱而删除任务。

实际生成计数再聚合后的 MAE 单独报告，区分均值模型误差与有限 400 细胞采样误差。训练/验证早停指标、此处本地指标和官方指标分别命名，避免混用。

### 7.2 官方实现的六项诊断

评估依赖固定到 `ArcInstitute/cell-eval2` 的提交 `5e64833518a6603a0301cbe28185d49c30f4a986`；准备时验证该提交、实际安装来源和锁文件一致，不能在执行时跟随 `main`。固定实现文档列出的六个成员如下。[固定版本评分说明](https://github.com/ArcInstitute/cell-eval2/blob/5e64833518a6603a0301cbe28185d49c30f4a986/docs/metrics.md)

| 指标键 | 原始值方向 |
|---|---|
| `pds_cosine` | 高为好 |
| `expr_mse_unbiased_capped_norm` | 低为好 |
| `de_wilcoxon_lfc_nmae` | 低为好 |
| `de_wilcoxon_direction_fidelity_yield_raw` | 高为好 |
| `de_wilcoxon_direction_reach_raw` | 高为好 |
| `de_wilcoxon_sig_jaccard` | 高为好 |

采用固定版本的 `vcc2026`/v2 配置，显式保存展开后的评估配置、基因/任务列表、target map、控制池和运行模式。目标基因排除须遵循该版本实现；PDS 的排除面板不能简化为手写的逐行删一个靶基因。评分器的归一化尺度也不能直接替换成本轮训练用的 CP10K。

本地公共数据的未测量基因先按固定可评分集合裁出双方共同视图，不能填零冒充真值；输出标记 `local_surrogate`。原始六指标不在相同尺度，**不直接求平均**。首轮不制作“官方总分”；如后续建立本地基线/重复参照 bundle，应独立版本化，并明确其分区、面板、参照身份。无官方参照不能复刻榜单标度。[官方分数解读](https://vcc-cli-wiki.virtualcellchallenge.org/)

按模型输出每个背景、两类主要靶基因分层的结果。PDS 依赖面板内竞争对象，每次比较必须使用完全相同面板；不同分层的 PDS 不作绝对横比。所有 NaN/排除项报告原因和数量；不能悄悄靠删任务提高平均分。

### 7.3 置信区间和成功判据

使用任务级成对 bootstrap 比较模型差异，2,000 次。每次在各测试背景内对靶基因任务重采样，最后对三个背景等权平均；样本量不足时仍可展示区间，但必须标记为描述性，不能将退化的 bootstrap 区间解释为高确定性；所有模型复用抽样索引。同一靶基因跨背景重复时，补充以靶基因为簇的重采样敏感性结果。400 个生成细胞不作为 400 次独立实验。

三个背景不足以估计普遍跨细胞系泛化的不确定性，CI 只解释为这些固定背景/任务下的不确定性；必须同时展示每个背景的效应和三个模型种子的结果。

以下研究支持判断保留原数值阈值，并以主分层三个背景各至少 30 个合格任务为前提；严格子集使用至少 20 个任务的原门槛。任何背景不足时，不宣称满足完整的研究支持标准，也不改成只汇总样本充分的背景。负结果或小样本描述性结果可以完成工程交付，但完整性失败不能。预先定义以下分开的判断：

| 判断 | 判据 |
|---|---|
| 实验交付合格 | 统一语料及隔离清单发布；三折、18 次拟合和 B0/B1/B2 完成；400 细胞输出与六项本地诊断完成；选定方法独立重训并生成 A/B/C 全量预测、通过格式验证；输入、代码、配置、结果、报告与 Artifact 可追溯 |
| 基线有预测价值 | M1 相对 B0 的主 MAE 降低 ≥ 5%，相对 B2 降低 ≥ 2%；对应 `L_M1 - L_baseline` 的成对 95% CI 上界均 < 0 |
| 背景条件化得到支持 | M1 相对 M0 的主 MAE 降低 ≥ 2%，差异 CI 上界 < 0；至少 2/3 背景改善，任何背景相对退化不超过 5% |
| 双重未见得到初步支持 | 满足任务数门槛的严格子集单独显示对 B0 和 M0 的改善及 CI；不与已见靶基因任务合并宣称通过 |
| 尚无结论/不支持 | 样本不足、CI 跨零、校准退化为 `α=0`、效果由单一背景支撑，或任一关键完整性检查失败 |

方向和幅度的诊断若出现一致恶化，必须在结论中说明，即使 MAE 达标也不将其描述为全面改善。假设不成立仍然可以形成合格的实验交付；不能靠追加测试驱动的特征和搜索来追求过线。

### 7.4 方法选择、独立最终重训与官方预测

**三折用于评估方法在固定公开背景上的表现和稳定性；最终预测使用按选定方法重新训练的模型。** 不按外层测试分数挑选一折 checkpoint，也不将三折 checkpoint 直接组合成最终模型。三折成绩属于评估阶段，不能当作最终重训模型的独立测试成绩。

方法选择在任何外层测试指标可见之前冻结，规则如下：

1. 候选为 B0/B1/B2/M0/M1。每折使用共同的 RPE1 验证面板，对 `0–79` 与 `80–89` 两个靶基因分层的任务宏平均重建 MAE 等权平均；M0/M1 使用三种子校准后效应集成，B1/B2 使用各折相同验证规则校准。
2. 对三折的上述 RPE1 分数等权平均，选择最低者；完全同分按 `B0 → B1 → B2 → M0 → M1` 的固定次序选择。验证记录、校准、训练轮数、候选分数和胜出模型组一并封存。RPE1 被重复用于开发选择，其分数不作为独立泛化证据。
3. 外层 H1/HepG2/Jurkat 结果仅用于评估和报告，不反向改变胜出方法。若 B0 或 B2 胜出，最终采用该统计方法，不强制选 XGBoost，也不因负结果追加搜索。
4. 完成三折评估后，新建 `final_refit` run，引用基线 run 的冻结选择记录、语料版本和方法配置。按最终监督范围重新构建统计量、拟合预处理器并训练模型；静态图等确定的外部先验可引用固定版本。

**最终监督范围 Q16 待确认，不作默认授权：**

| 选项 | 最终训练方式 | 轮数与校准 |
|---|---|---|
| A：释放此前保留的公开标签 | 可纳入 RPE1、原外层留出背景及 `90–99` 靶基因中合格的公开监督；保留来源/QC/配对和显式规模规则，不使用官方 A/B/C 隐藏标签 | M0/M1 的每个 seed 使用对应 seed 三折最佳树数的中位数从头训练，α 使用对应三折验证所选 α 的中位数；B1/B2 的 α 同样取三折中位数。规则在查看外层分数前冻结，无最终早停集 |
| B：保留独立验证 | 最终训练仍保留明确的验证背景/任务，不把这些标签并入监督拟合；实际范围在最终配置中冻结 | 采用 §5.4 同样的验证早停和 α 网格；不允许用外层测试结果替代验证 |

上述 A/B 是待选择的执行方案；不能把 Q14 的“重新训练”解释为已批准释放全部公开标签。该项不影响前述统一语料和三折流程。若最终选择 M0/M1，保留 seeds `[17, 29, 43]`，另外拟合 3 个模型并按同一效应集成规则生成预测；若选择 B0/B1/B2，则在最终范围上重新构建相应预测器，不制造无意义的 XGBoost 拟合记录。

最终 A/B/C 仅提供 NTC 特征和生成深度。使用固定控制分池规则构建各背景 `C_feat`，复用已拟合的变换；不将 A/B/C 用于重新拟合 PCA 或选择模型。使用 §6 的计数采样器、主生成 seed=101，为所有 900 个任务各输出 400 个细胞。保存输出文件哈希、基因顺序、目标覆盖、缺失支持/回退比例、整数和稀疏结构检查及固定 CLI 的验证结果。官方隐藏标签不可用，因此不生成虚构的官方分数；生成文件并不等于已提交榜单。

### 8.2 语料建设与训练预算分开

语料调查、转换、去重、QC 和发布单独记录时间、存储及资源，不挤占原有基线训练评估预算。未约定语料建设总时限，不另设 Agent 自行决定的时间门槛；按真实工作量持续完成，确有外部障碍则记录隔离或失败原因。

以下保留为三折基线 run 的预算；从读取已发布语料开始计时：

| 项目 | 上限 / 处理 |
|---|---|
| CPU | 最多 16 线程，一次一个拟合 |
| 内存 | 进程树 RSS 目标 ≤64 GiB，硬停止 80 GiB；GB10 为共享内存，不把系统内存和显存相加 |
| GPU | 不作为训练前提；评估启用 GPU 须预先固定配置、依赖及驱动 |
| run 新增磁盘 | ≤120 GiB；空闲低于 100 GiB 时停止开始新步骤 |
| run 输入核验 / 预处理 | 8 小时预算，不含共享语料建设 |
| 每次拟合 | ≤2 小时，最多 1,200 棵树；18 次拟合总预算 36 小时 |
| 评估 | 12 小时，逐背景、面板及生成种子流式执行 |
| 三折基线整体 | 墙钟 60 小时预算；不是整个语料、训练及最终导出的总工期 |

扩展语料后，训练行数按 `sum_c(入选任务数_c × 最多1024基因)` 计算，不能继续沿用“每折只有三个训练背景”的约 246 万行估计。用固定 5% 训练任务测量吞吐/RSS并外推，检查属于当前 run 的工程步骤，不产生独立 preflight run，也不使用测试效应选配置。测量表明既定预算不可行时先登记依据及修订，不能悄悄减少模型、种子、外层折或测试任务。

最终重训和官方导出另列配置与耗时估算，继承上述 CPU、内存和磁盘约束，按实际胜出方法和语料吞吐确定工作量；不把额外拟合混入 18 次或隐含算入基线 60 小时预算。

正常结束条件为既定树数或 §5.4 的正常早停，以及规定评估/导出全部完成。输入哈希不符、标签污染、非有限损失、运行时不匹配或资源越界时保存完整恢复状态并记录失败。预算耗尽、中断、仅完成检查都不算交付完成。少于 30 个测试任务和性能不佳不属于自动中止条件；真实标签与有效控制缺失则不能以降低真实性要求绕过。

## 10. W&B 与可观测性

```python
wandb.init(
    entity="yjcyxky",
    project="virtual-cell-challenge",
    group="exp001-context-pair-xgb",
    id=run_id,
    name=f"{run_id}-{run_kind}",

    config=resolved_config,
    dir=str(run_dir / "wandb"),
)
```

恢复时校验本地身份与 W&B 同一 id，并显式采用对应恢复模式。训练记录树数、损失、RPE1 任务宏指标、最佳轮次、α、耗时和资源；预处理记录覆盖、去重、QC、角色和输入输出哈希。测试记录模型组、折、分层、指标有效分母、CI、生成种子及描述性标记。资源每 30 秒采样。

| 基线 run：检查与视图 | 锁定环境、实际 config、资格/覆盖报告、split、控制分池、各折特征 | 物理背景及靶基因隔离，无重复控制跨池；小样本标记清楚 |
| 基线 run：工程校验与训练 | 必要的合成边界验证、吞吐估算、B0/B1/B2、18 次 M0/M1 拟合及校准 | 无测试驱动选择；RPE1 方法选择与全折预测先封存 |

| 报告与清理 | Experiment REPORT、W&B/Artifact 固定引用、复现记录和必要代码 | 说明实际状态、资源、局限、失败和负结果；删除本次临时或被替代实现，不删除共享数据和历史 run |

重点验证会破坏结论的边界：物理背景/条件/重复细胞隔离、靶基因别名和严格测试角色、匹配批次、分池、缺失基因掩码、权重、归一化、`Δ=0` 重建、整数计数输出、完整任务覆盖、同配置恢复及配置变化拒绝误续训。哈希或锁不符、输入断链、零文库等须可靠失败并留日志，工程校验不能替代有效训练。

复现采用同一锁和 CPU 模式，split/映射/整数计数哈希一致，浮点预测在预先记录的容差内一致，主 MAE 绝对差 ≤`1e-6`；超出时解释并报告，不在见到结果后扩大容差。恢复测试应验证真正的训练状态连续性，而不只是日志接上。

REPORT 至少包含语料版本及调查范围、接纳/隔离理由、独立背景与任务数量、全部折/模型/种子结果、相对各基线的差值及 CI、研究门槛是否满足、胜出方法的 RPE1 依据、最终重训范围、官方文件验证状态、实际资源消耗、W&B 链接和平台/采样器局限。三折评估与最终模型分别列示；普通性能、负结果、小样本描述性结论均可交付，未运行或失败项目不得标记完成。

## 12. 如何接到模块假设

本轮冻结以下后续接口：`context_features(c)`、`gene_features(g)`、`pair_features(p,g,c)`、`predict_delta(p,c,G)`、`decode_counts(...)`、`evaluate(...)`，同时发布 split 和比较预测的版本化 Artifact。

后续分别新建实验，复用固定输入、评估面板和计数采样器：

1. 在基因分支上增加静态生物模块，并与相同维度的 PCA/NMF、匹配模块大小的随机分组比较。
2. 分别允许模块响应 `z` 和映射 `W` 随 `h_c` 变化，拆开两种背景条件化的贡献。
3. 比较模块单独预测与模块加基因残差，检查模块内方向是否被过度平滑。
4. 均值预测确有稳定收益后，再单独研究冻结基础模型表示和过度离散的单细胞生成器。

这些比较须在新实验中登记，引用本轮明确版本而非可变工作目录。如果反复用本轮测试背景选择模型，它们将成为开发基准；后续确认模块假设还需要新的保留背景或预注册的外层评估，不能继续把同一测试集称为未使用的最终验证。
