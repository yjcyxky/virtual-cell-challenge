# 初始线性响应路线：C-BASE / E-BASE

`init-linear-s01` 已完整训练、生成并完成两面板×四臂官方评分。**当前条件线性实现未通过优越性判据**：相对主面板最佳参照 shared，280 靶 Overall 差 −0.049731，25 个官方重叠靶差 −0.073124。保留有效对照，搁置该实现优越性的主张；这不是对所有线性模型或背景信息的否定。

## 执行与范围

- Experiment=`init-linear`，run=`init-linear-s01`；S2-H1 / context-seen / seed=1。训练为 K562、RPE1、HepG2、Jurkat；H1 扰动标签仅进入 evaluator。4 个训练背景来自 2 项来源研究，测试为 1 个背景/1 项来源研究，生物独立重复数 unknown。
- 四训练背景分别有 9,864 / 2,392 / 2,392 / 2,392 个任务、1,914,028 / 236,324 / 140,454 / 250,792 个扰动细胞，合计 17,040 个背景×靶点任务和 2,541,598 个细胞。完成精确 masked ridge 解，训练 MSE=0.00125619；它不是泛化指标。
- 输出完整官方 18,533 基因轴，每靶 400 个计数细胞。H1 输入 NTC=18,400，评分 NTC=19,104，物理身份不交叉。主面板真实参考=123,153 个细胞，其中真实扰动细胞=104,049；官方重叠参考=28,372，其中真实扰动细胞=9,268。真实细胞每靶最多 400，不上采样真值。
- H1 评分轴为实测 18,074 基因；训练来源并集实测 10,916，H1 评分基因中 7,292 个无训练响应监督，模型在这些位置设 zero-Δ。H1 未测的 459 个官方基因仅作输出补全，不参加本地评分。生成器的文库重归一可能影响最终计数，zero-Δ 不等于每个基因计数恒定。
- 280 个 context-seen 靶点中，181 个仅 K562 支持、99 个有四训练背景支持；25 个官方重叠靶均属前者。辅助面板与官方重叠面板分开评分，不能据此宣称完整 2026 challenge 成绩或全局未见靶点泛化。

## NTC、效应偏移与未决归因

zero 使用独立输入 NTC 重采样，对比评分 NTC。官方 Jaccard 日志记录主面板预测侧仅 22 个显著 `(target,gene)` 对，官方重叠面板 3 个；这是多个重采样伪扰动的重复计数，非独立发现。没有观察到大规模 NTC 伪 DE，但不能据一次采样证明所有 batch 无漂移。zero 的 PDS raw 接近 0.5，与低扰动特异信息一致。

shared 在主面板有 973,951 个去自身靶基因后的预测显著对，linear 为 731,322，真实侧为 533,306；这些数量受样本量、缺测、效应幅度和官方过滤共同影响，不能直接当作生物真假判定。当前现象值得检验响应幅度及条件共有偏移，而不是先增加模型容量。不同背景测量轴导致 CP10K 分母不同，log-shift 后截断与文库重归一也可能改变幅度；本次未分离这些因素。

linear 与未正则 shared 同时存在条件项、正则收缩和参数耦合差异，不能把 −0.049731 直接解释为“NTC 背景信息有害”。下一步 `C-CONDITION-ABLATION`：在相同 target-ID 岭回归、alpha=1、细胞权重、训练数据、生成器与评分协议下，仅禁用全部 NTC 条件项，使用独立 run `init-linear-nocontext-s01`。以现有 linear 为配对控制；shared/source 继续作为参照。候选超过控制 0.02 且官方重叠不下降超过 0.02 才产生本地筛选线索。节点保持 draft，完整配置、代码与判据核验通过后才可启动；未假称已完成新训练。

若消融有信号，先在其他背景复验；若没有，转向正则/响应空间与生成映射的分离诊断。数据 QC 仍需基础/QC/等数量覆盖随机三臂，GO 先验仍需全局靶点留出与匹配随机对照；两者不因本次结果自动获得效果证据。
