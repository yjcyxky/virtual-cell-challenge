# DepMap 监督对齐：未见靶点响应的机制比较

Comparison: `C-DEPMAP-RESPONSE-ALIGNMENT`。首批完整方案开发实验，无超参网格，不是论文逐项复现。

KnowGraph attention: `BIO-COESSENTIAL`, `PAP-F-DEPMAP-GEOM`, `PAP-F-CONTROL`, `MY-EFFECT-EMITTER`, `ST-WILCOXON`。原始功能邻域可能只迁移模板；这必须由配对对照、官方六项和去模板/通路能力共同判断。

## 首批资源和明确终点

一次冻结批次：五背景全部 S3 joint-OOD 折，加 S2-H1 已见靶点 LOCO 折；每折独立拟合七个方案、seed 930，共 **42 个完整 fits**。S3 共 3,320 个冻结合格靶任务，S2-H1 为 280；每方案正式生成 3,600 群 × 400 细胞，七方案合计 10,080,000 细胞，完整逐靶诊断和官方评分。当前五背景均为开发证据，不称未触碰测试集。

完整参考与 anchors 已另以 `C-LOCAL-EVAL-SUPPORT-R4` 登记为 13 个 S2/S3/S4 外层划分、15 个全靶面板；先前执行因累计稀疏索引溢出、压缩随机读取及重复指针读取归档，不构成方法证据；R4 复用固定哈希的银行及已完成 H1 面板。本轮预测器预算优先给功能先验最需要解决的未见靶点。**不把 15 个评价器面板称为 15 个已拟合模型**。其余 S2 和研究留出模型确认属于后续资源决策；无论首个方案得分如何，本批七方案和六折均完成。

共享单 GPU，每次一个正式训练/评分进程；每 MLP 400 epochs、batch 256，预计几分钟至数十分钟/fit，生成与全量诊断占主要总成本。每个 Ridge 最多 200 次共轭梯度迭代、相对残差容差 1e-5；完整执行后报告实际残差，不把未收敛说成线性方法已饱和。模型权重、PCA、训练恢复状态、完整官方轴 latent 响应、实际计数和结果均保留。技术故障沿原身份恢复，科学条件改变另登记。

DGX Spark 的 NumPy 大数组大页建议曾触发持续内核碎片整理：相同 1 亿项整数分配及转浮点，普通页约 0.32 秒，大页建议下初始分配 25 秒超时。该批固定进程环境 `NUMPY_MADVISE_HUGEPAGE=0`，在绑定前检查并写入实际配置；只控制内存分配，不改官方评分器、数组值、随机种子或数学运算，不调整系统全局大页设置。

## 数据、表达空间和测量映射

只读取当前外层划分允许的 source contexts 和 training targets 的观测统计。训练标签来自全部结构允许 native 细胞的 bulk 组成；细胞数量、guide/batch 效率观测和真实 n 单列，不用它们增加独立背景数。当前不额外做敲低或响应强度硬筛，不把 unknown 作为失败；可靠剂量估计只用于来源覆盖/诊断，尚不声称已消除剂量混杂。

令背景实测集合为 M，原始组总和组成为 p，使用

`p⁺_g = (50000 p_g + 1) / (50000 + |M|)`。

学习的全官方轴 latent 响应 z 是平滑组成的 log 比率，只有差值可识别。source 标签为 `log1p(CP50K_pert) - log1p(CP50K_input_NTC)`，在 `M \ {当前靶点}` 上减去行均值。缺测与当前自身均不贡献主损失。

Ridge/MLP 的预测先限制到 M，再作相同的下游中心化后与标签比较；这等价于先计算 `q⁺_M = normalize_M(p⁺_NTC exp(z_M))`、再比较中心化 log 组成。归一化分母随真实测量轴变化，缺测不补零监督；不会把 full-axis 总量的零填充当成来源分母。每 context 等权，每 context 内靶任务等权，每任务按实测下游基因数归一化，不按细胞数扩大某来源权重。

推断明确为 `NTC baseline + compositional log response`。在许可的目标输入 NTC 基线上应用 z，重算实测集合分母、移除同一个伪计数、投影非负组成，量化投影比例和最终 bulk 实现误差。输出参数为完整 18,533 官方轴；本地 counts 仅在真实测得的子轴评分。无任何 source 监督的读出固定零 latent 响应并明确标为回退，不把随机未训练权重作为补全证据。完整官方输入时同一解码函数消费完整官方轴。

为使“未监督坐标零 latent”可识别，所有方案先把预测在全轴的来源可监督坐标（排除当前自身）上中心化，固定共同 log 响应平移自由度，再将从未监督坐标设为零。source-only 模板也在其可监督坐标上固定零均值。此约定不改变训练中的逐实测集合中心化损失；它决定了新增未测坐标相对已学坐标的中性参考，不能交给任意截距或初始化决定。

Shared 使用同靶点直接监督坐标作为中心化支集，其余坐标严格保留零；这样也满足全可监督集合上的零和约束，不会让中心化给直接缺测坐标新增响应。其余方案在全来源可监督坐标上固定该约定。

自身在损失中排除，生成时固定其 **bulk 组成残留为输入 NTC 的 20%**；剩余质量分给下游。该固定规则不属于学习能力，所有方案一致且在统计中单报；不保证每细胞 CPM 残留都恰为 20%。非靶邻近基因、周期/生长/应激基因保留，HVG 仅用于协方差诊断。

## 七个完整方案

九轴登记按实际实现：数据为 `D1`（合并允许来源），Ridge/MLP 的背景平衡由固定损失权重完成，记为 `O5`；它们没有按背景等量抽样，不能记作 `D2`。解析式对照保留 `O0`。整包比较包含 R/A/L/O 的变化，同架构真实/置乱先验之间只改变描述符对应关系。

1. **Shared**：同靶点在允许 source 的中心化响应，按实测坐标跨背景等权平均；未知靶点下游零响应。无监督读出零响应；固定自身规则仍单列。
2. **源模板**：训练任务的 context 等权、靶点等权均值，无靶点区分输入。
3. **raw kNN**：原始 DepMap 依赖向量余弦最近 5 个合法 source 靶点，等权转移其 Shared 响应；每读出按邻居实测覆盖归一化；没有邻居监督的坐标回退源模板。无响应对齐，seen 靶点可匹配自身。
4. **DepMap Ridge**：源训练靶点内拟合 PCA 50；带掩码/中心化的二次响应损失与 L2 正则。alpha=10，实际正则系数为 `10/(训练任务数×完整基因数)`，截距只加 1e-12 数值约束。共轭梯度求解同一冻结二次目标；完整保存求解状态。
5. **置乱 Ridge**：同一 PCA、同一覆盖、同一维数、同一模型/损失/求解预算，只置乱靶点到描述符的对应关系。
6. **DepMap MLP**：50→256→256→全轴，ReLU、无 dropout；Adam lr=5e-4、weight_decay=1e-5、cosine decay 400 epochs、梯度裁剪 1、batch 256。沿用作者代码学习率而非正文 5e-5，且使用本任务观测/损失，不称精确论文复现。
7. **置乱 MLP**：与 MLP 相同配置，只置乱描述符对应关系。

DepMap 固定为官方 24Q2 Public v1 CRISPRGeneEffect、发布 MD5 和本地 SHA256。只取准确符号匹配，重复符号排除并报告；不猜别名。该发布矩阵有 1,150 个细胞系、18,443 条基因描述符，完整缺失谱为零，但逐基因测量覆盖最低约 2%；存在 13 种原始缺失掩码。整条先验可查不等于其细胞系测量充分。缺失数值按 source training target 的逐特征中位数填充；PCA 只拟合有覆盖的唯一训练靶点。置乱在 PCA 拟合后进行，按来源背景成员集合×评价靶点成员标记×原始细胞系有限值掩码分组置乱，保持每个来源背景及评价集合的特征分布、先验覆盖和缺失模式；分组仅用已知身份和外部先验的缺失掩码，不读取留出响应，单元素组保持原对应并报告未变比例；不接触响应标签拟合先验。缺先验的 Ridge/MLP/kNN 使用源模板回退；Shared 和源模板不消费先验预测，只报告相同覆盖。

训练中缺少整条 DepMap 描述符的来源靶点仍保留，以零 PCA 坐标输入 Ridge/MLP，相当于无靶点描述的中心输入；它们对截距/共同响应有贡献，不能提供特异映射信息。该规则与推断时的模板回退分别记录，真实与置乱方案一致。预测头在 CPU float32 上执行，训练使用 CUDA；成对方案使用同一执行路径。

执行前按固定 CSV 列名核对：S3 的 H1/K562/RPE1/HepG2/Jurkat 评价靶点先验覆盖分别为 69/70、1898/1954、414/432、415/433、413/431；S2-H1 为 277/280。这只是输入覆盖，不代表响应可迁移或先验有效，全部缺失靶点仍保留在评分面板。

固定 seed 930 的外部输入核对显示，精确掩码分组后的 S3 H1/K562/RPE1/HepG2/Jurkat 评价覆盖靶点中，仍保持原描述符对应的数量分别为 1/69、6/1898、12/414、12/415、11/413；S2-H1 为 11/277。正式 fit 仍保存实际对应和比例；置乱对照不是每一行必然改变，不能忽略这些保留项。

描述符保留该发布版本的全部细胞系特征，不按评价背景删除外部依赖谱列。此处的背景/靶点留出指转录响应监督留出，不等同于从全部外部功能测量中留出背景/基因；外部先验的可用边界单独声明。

## 生成、评分前能力诊断

全部方案固定采用 `E-POPULATION-EMISSION` 的总体校准、独立抽样及文库守恒随机取整，最多 128 次校准、smoothing=1e-6、L1 tolerance=1e-7。每靶 400 预测细胞，paired seed 只依赖外层划分、背景和靶点，与模型臂无关。深度继承许可目标 NTC 的实际分布，不强制每行 20k、不人为固定稀疏度。该生成器已通过抽样/整数工程验收，但 DE 保真度仍有限。

顺序固定为拟合→冻结 checkpoint→全量生成→逐靶统计诊断→官方六项。诊断复用已有统计函数，保留 raw/CP10K/mean-log/bulk 多空间矩、文库/检出数/零率、Fano/方差比、重复/NTC精确复制率、自身残留/低表达覆盖、源监督与回退分层；先验另报实际细胞系测量比例、原始平均依赖值，以及训练源 PCA 白化半径。半径超过来源训练靶点的 p95 和测量比例低于 0.9 只作固定诊断分层，不筛样本，也不称正式 OOD 检验；这些分层始终使用真实基因描述符，置乱臂也沿用相同分层。协方差选取 input NTC 的最多 128 个非面板靶基因。逐靶另保存检出基因数 CV，逐基因保存 Fano（均值为零时不可定义）、mean-log 响应和 mean-CP10K 上的 log2FC（1 CPM 伪计数），与 bulk-log-CP50K 分开。所有矩阵全量扫描 counts 硬约束；另核对 CSR 存储元素数、逻辑容量和 int64 指针。这里是靶点数可变的本地评价矩阵，不把官方固定提交档案的 nnz 上限套到更大的本地面板；官方导出另行核验提交容量。保存每个靶点的实际直接 source 背景、全轴/实测子轴监督量和已知剂量；unknown 显式保留。

每 fit 的每个评估背景执行 3 个相同 n 的零响应、input-resample 和不交叉 real-NTC null；零响应走同一组合解码器和生成器，必须同时通过解码恒等与计数恒等，再调用官方 DE 核对新增伪 DE。无自身规则的零 latent 显式返回原 baseline，避免 exp/log 舍入误差错误触发平滑/IPF；固定自身规则不应用于明确的 null 身份任务。同一 null 还保存深度、稀疏性、Fano、归一化方差及 input-NTC 选定基因上的协方差统计；共同参照是评分 NTC 的前半，真实 null 从不交叉后半无放回抽取，三次抽样不作生物重复。另在 4 个身份哈希靶点各做 3 次独立非零生成，报告群均值方差/组内方差关系，保留计数；这些重复不增加生物独立样本。

全部面板靶基因从模板/几何/通路诊断中排除。源训练模板解码到目标许可 NTC，作正交方向投影；真实响应只在评价阶段读取，用同一个 scoring NTC 原点比较 prediction 与 truth。报告去模板残差相关/幅度/误差，固定 Reactome 通路恢复、弱响应与真实 n/coverage 分层。模型生成若出现硬约束失败则停止正式评分并修复；统计偏离完整记录，不能删异常靶点追分。

源模板可能未覆盖目标背景的通用响应方向。因而在 checkpoint 和预测已冻结后另做两项**评价专用**诊断：分别减去 prediction/real 跨靶点质心，比较剩余靶点差异；再把两者的中心化向量投影到真实目标背景平均响应方向的正交补，比较残差。这个方向使用了留出真实响应，只用于解释评价结果，不进入拟合、特征、解码、计数生成或超参选择；不能称为模型可取得的 zero-shot 输入。它也不是论文的 ANOVA 交互项或固定共同质心的 pref 指标。预登记的 source-template/PDS 晋级门槛仍单列，新增诊断用于检查共同响应残留是否造成误读。

强弱四分位是按参考矩阵的**观测** bulk 响应 RMS 分组，尚未扣除估计噪声，不称为固有生物响应强度；必须结合真实 n 分层解释。官方 DE 的真实侧 gate 会减少各项有效靶点，逐指标报告有效数；另报真实显著对在预测 DE 表中的缺失数，避免把筛除排名候选误判为方向能力提高。

每背景的诊断身份文件固定 checkpoint、预测、完整响应/测量掩码、参考面板、实际配置及执行代码的哈希；恢复时全部一致才复用。计数、null、残差/通路和读出诊断完成后保存 pre-score-completed 状态并记录到原 W&B。

官方严格复用该 full-support 精确面板的已冻结 baseline/real-bundle/5 anchors、同一 cell-eval2 commit 和 vcc2026 preset。每份新预测自己的诊断不可省略。六项 raw、normalized、Overall 和实际有效数同时报告；未定义归一化保留未定义，不删除指标。seen/unseen、n、官方靶点、缺先验分层仅报告 raw，不拿全体 anchors 作子群标尺。诊断 DE 集合只是辅助表，不冒充正式指标。

## 晋级、停止及归因边界

主问题是未见靶点特异信号：以 S3 五背景为配对单位，主观察 raw PDS。候选相对 Shared/源模板及同架构置乱的平均增益至少 0.02，且至少 3/5 背景同向，才作为机制信号；同时要求去模板残差相关平均改善至少 0.02。真实先验只赢源模板而不赢置乱，不能支持功能映射有效。

完整方案晋级还要求可定义背景上的配对 Overall 平均改善至少 0.02，并检查 Expression accuracy、DE fidelity/Jaccard 没有只在高 n/强响应子群改善。所有六项均展示，若 raw PDS 与表达/DE 显著冲突则记为局部能力线索，不能宣称全任务改进。仅一个 seed、五背景/三来源，背景间相关；不以靶点/细胞数夸大跨背景显著性。

42 fits 全部回收后关闭该有限比较。没有信号则停止本路线局部 rank/学习率网格，按监督覆盖、残差、剂量和分布诊断决定换机制；有信号则另登记未用 S2/研究留出与独立 seed 确认。**本批不自动提交 leaderboard**；默认暂缓，直到完整配对比较及后续确认支持提交。不能把固定敲低、继承 NTC 形态或先验相似当成学到机制。
