# 完整留出面板与本地评分支持

Comparison: `C-LOCAL-EVAL-SUPPORT`。此路线实现有界内存的完整参考群体与评分；不拟合预测模型。

KnowGraph attention: `EXP-LOCAL-EVAL`, `EXP-LOCO`, `ST-WILCOXON`, `PAP-F-PATHWAY`。

## 数据、范围和停止条件

冻结 S2/S3/S4 的 13 个外层划分、15 个背景面板，取每折全部结构合格靶点。保留最多 400 个唯一真实细胞，按物理身份哈希选择，绝不复制不足细胞。复用已校验观测表的输入/评分 NTC bank；二者不交叉。H1 仅以输入 NTC 确定的原抽稀率对 raw 计数做二项抽稀，其它低深度背景不补高。靶点的抽稀种子由背景、源文件和块行号固定，区别于旧有限 bank 的随机实现；全部新面板重新建立 anchors。

不按响应、敲低程度或可评分性筛选。训练统计缓存仍为全量 native 观测，本路线的 reference 为冻结的最多 400 个细胞深度视图；两种估计范围显式区别。缺测不补零；矩阵保留每背景实测官方轴、顺序和完整轴位置。

## 评分与诊断

逐面板执行冻结官方 baseline、real-bundle、5 个 replicate anchors。仅复用官方接口，不改变指标公式和默认归一化。每面板完成 real-copy 和固定循环靶标签置乱两种仪器对照，完整保留六项 raw/normalized/Overall；两对照不是可部署模型。

两种对照在评分前保存预测/检查点哈希，逐靶整数/空细胞/文库/稀疏/raw和CP方差/Fano/重复行/与输入NTC精确匹配/自身残留表达统计。联合结构在输入 NTC 选出的最多 128 个非面板靶基因上计算。保存逐基因矩和不同表达空间响应；共享能量、去共享参与率、20,000 对固定随机靶间余弦只作描述。真实比较两侧使用同一个评分 NTC 原点；内部响应结构使用许可的输入 NTC 原点。源背景允许训练靶点的均值 bulk Δ 提供诊断模板，排除自身后按背景等权聚合，不使用留出真值估计模板；该方向只作辅助诊断，不作为预测器有效性证据。通路使用固定 Reactome、至少 5 个实测非面板靶基因，报告正交残差恢复。

各面板单列真实 n<100 / 100–399 / ≥400、seen/unseen、官方靶点、实测轴覆盖。分层报告 raw，不用全体 anchors 冒充子群 normalized。细胞数匹配 DE 已由总体生成校准覆盖固定 4 靶诊断；本批不通过新增随机种子筛选可评分面板。

## 有限预算与决策

单个无预测器拟合 run，seed 930；五背景全量参考扫描，15 个新 bundle，30 次完整官方六项评分；保持全部真实计数、诊断和分项产物。主要验收 `support.fraction` 为两种对照六项和 Overall 均有定义的面板比例，全部 15 面板通过才称完整支持。若仍有退化，按官方拒绝保留 raw/未定义 Overall；完成一次批次后停止面板/seed 调试，模型在预定有效范围继续研发，不把这一点变成无限期前置。

同时下载并校验官方 DepMap 24Q2 v1 CRISPRGeneEffect 原件，作为后续独立拟合的固定外部描述符来源；本 run 不拟合 PCA 或响应映射。文件落在本 run cache，记录来源 URL、发布 checksum 和本地 SHA256。拟合范围另由模型 run 冻结。

预计占用单 DGX Spark、约 120 GB raw I/O 和数十 GB参考/诊断存储；CPU 上有界读写，GPU 执行官方 DE。单面板技术失败保留并按同条件恢复；不以预检、部分背景或部分指标冒充完成。无 leaderboard 提交。
