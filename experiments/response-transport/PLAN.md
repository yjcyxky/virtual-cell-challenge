# C-MECHANISM-PORTFOLIO：先比较完整机制，再配置下一轮资源

本轮比较、节点与判据以 DAG 的 `C-MECHANISM-PORTFOLIO`、Ledger 的 `E-MECHANISM-PORTFOLIO` 为准。本文件解释冻结实现；不维护另一套实验状态。

## 搜索决策与资源配置

近期小幅收益集中在条件 ridge、已监督响应保持不变的缺测补全及细胞过滤。它们不回答更广泛的任务、响应函数与生成分布选择。本轮给三种机制各一个完整配置：跨背景神经响应迁移、组成 logFC 与细胞模板校准、均值/离散度与 Gamma-Poisson 生成。允许 T/D/R/A/L/O/I/G 联动，结论只针对整包。线性头和去 NTC 消融留在 draft，不是任何路线的启动前置。

三个配置在看到首个候选结果前同时冻结。神经模型预算为 4,096 步，每步 8,192 个标量响应例子；另外两种是遍历全部允许原始细胞后的完整解析拟合。每条生成 280×400 个细胞，在同一主面板和官方重叠面板完成两次正式评分。每个 Experiment 独立 uv 环境，顺序运行；首轮预算为三个拟合、六次评分，不追加 H1 参数网格。预算按完整机制评估分配，不以相同 epoch 数假装不同算法成本相同。保存实际耗时、内存、覆盖和 W&B 成本记录。

机会成本：神经迁移不再把已监督 shared 锁死，能修改所有有测量来源的响应；组成模型改变均值的表达空间及 count 逆映射；分布模型直接研究一阶与二阶矩，但牺牲基因间相关结构。三个方案均可作用于当前 280 个已见靶点；官方 300 面板中训练可监督 272，28 个无来源靶点仍是未解决的主要范围限制。本轮不把大量计算再用于同一个表示或 QC 分支的微调；若三条都未达标，下一轮需改变机制或支持范围。

## 共同数据与评价

S2-H1/context-seen/seed1。训练为 K562、RPE1、HepG2、Jurkat 四背景、两个研究；2,541,598 扰动细胞、17,040 背景×靶点任务、9,867 靶点。H1 只向模型提供 18,400 个 input NTC；19,104 个 score NTC 及扰动真值只进入评估和明示的事后诊断。主面板 280、官方重叠 25；H1 已用于选择，只形成开发证据。

输出完整官方 18,533 轴；H1 按真实测量的 18,074 基因评分。四训练背景测量并集 10,916；保留各背景掩码，不把缺测当监督零。所有方案使用相同允许细胞、物理划分、400 生成细胞、每靶 seed+冻结索引，以及冻结的官方 cell-eval2 `5e64833518a6603a0301cbe28185d49c30f4a986` / vcc2026 配方。`linear` 只是历史评分接口中的候选槽名，不表示候选是线性模型。

复用 init-linear 的 35 个固定输入及 reference/bundle 文件，逐项校验并复制到本 run。共享输入适配器允许登记的模型/生成器变化，但强制 benchmark、基础数据、划分、seed、评价及生成群体大小一致。基线为已完成 `masked-response-shared-s01`：其配置、checkpoint、预测及两个面板全部评分文件独立核验，不冒充本轮拟合。三条新预测均重新评分；不引用 exp007 的分数。

源文献是外部假设依据：[Ahlmann-Eltze et al. 2025](https://www.nature.com/articles/s41592-025-02772-6) 讨论简单预测器、来源响应表示及背景表达差异；[Nadig et al. 2025](https://pubmed.ncbi.nlm.nih.gov/40259084/) 研究效应测量误差、跨细胞类型与剂量差异。它们不证明本项目迁移网络有效。组成/分布路线也受到文献卡 L09/L10 的条件扰动建模问题启发，均不是 scGen/CPA 复现。

## 神经响应迁移

训练四背景形成 12 个有向 source→destination episode。每对只用双方真实测量基因和共有训练靶点；每步均匀抽背景对，再均匀抽靶点与基因。靶点按 SHA256(`1729:target`) mod 5==0 分入诊断集，其他靶点进入优化；诊断只看训练背景，不选择 checkpoint。完整迭代完成后使用最后一步模型。

响应空间仍是平均细胞 log1p CP10k 的差。特征为 source Δ、两个 NTC 中 readout 与扰动靶点的表达、靶点测量标记、source 支持量、on-target 标记及 Δ 与上述特征的乘积，共 17 维。没有学习的 gene/context/target ID，也没有 destination 扰动标签输入。网络为 17→64→64→1，SiLU，末层无偏置，初始末层为零。令 d=Δ/0.1，预测为 `Δ + 0.1*(f(x)-f(x with d and d-products zero))`，使零来源响应严格映射为零；表达除以 5，支持量用 log1p(n)/log1p(1000)。

AdamW(lr=.001, weight_decay=.0001)、梯度裁剪 1、float32、确定性算法；每 256 步保存网络、optimizer、采样器、torch CPU/CUDA RNG、步数和配置哈希。恢复沿用原 run 并恢复完整状态。目标 NTC 只用于预测；对每个可用来源分别迁移，再按原细胞数/100 逐基因聚合。全局无来源靶点/基因的 Δ 为零。生成器沿用原 NTC logshift、文库恢复、随机取整。

## 判据与闭环

预定 signal：相对 shared 主面板 Overall 至少 +0.02，官方重叠至少 −0.02。全部三条完整评分后统一比较；一条通过则下一轮优先新背景或配对种子及必要归因，多条通过按主分、重叠非劣与成本排序。单次小涨分只记线索，不自动开启参数网格；未通过仅否定当前完整配置及范围。若未完成或条件不匹配，先恢复/修正，不能记阴性。

REPORT 汇报 raw 六指标、normalized 六项、Overall、有效数、逐靶配对差和波动（细胞/靶点重采样不冒充独立背景）。固定 400 个输入模板和 400 个隔离评分 NTC 做零响应诊断：logCPM 均值漂移及 Welch+BH 伪 DE 筛查；此辅助检验不替代或改写官方 DE 评分。涨分若主要来自生成分布校准，不能解释为生物响应更准确。

启动：`./reproduce.sh --run-id transport-mlp-s01`。完整 checkpoint 同条件恢复加 `--resume`。共用执行器在任何输出/W&B 创建前 bind；正式环境同步和拟合前须通过 execute 门禁，代码/配置/锁文件先提交。三条结束后分析、关闭 E-MECHANISM-PORTFOLIO、记录下一轮资源选择，上传模型与证据 Artifacts。
