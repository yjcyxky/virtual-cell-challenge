# C-MECHANISM-PORTFOLIO：三种机制整包的完整筛选

三个新 run 均完成完整拟合、280 靶点全轴预测、两个正式官方面板评分及 W&B 模型 Artifact。三条均未达到预先登记的主面板 +0.02 / 官方重叠不低于 −0.02 门槛；本轮证据为 **not_supported**，不晋级任何一个具体配置。没有得到优于 shared 的候选，也不作 SOTA 主张。

这是三种完整机制的比较，不是三项单因素消融。三个配置在首个候选结果出现前共同冻结于 `808773b`，后续提交只回收已完成节点。没有根据先完成的分数改剩余模型，没有先跑线性头作入场证明，也没有开启局部调参。

## 数据、协议与参照

S2-H1/context-seen/seed1；K562/RPE1/HepG2/Jurkat 四训练背景、两个研究，17,040 背景×靶点任务、9,867 靶点、2,541,598 扰动训练细胞。来源细胞保留率 100%，没有额外 QC 或删减；来源 guide/batch 的物理身份沿用冻结审计。H1 input NTC 18,400 与 score NTC 19,104 物理隔离。主面板 280 靶（181 个 K562-only、99 个四来源支持），官方重叠 25 靶均 K562-only。

输出官方完整 18,533 基因；H1 在实测 18,074 基因上评分。四来源测量并集 10,916，H1 中 7,292 基因缺少四来源测量。后一个数字只描述当前 H1 留出划分；最终五背景合训的覆盖不同。官方 300 靶中 272 有当前来源响应，28 没有。本轮只验证 context-seen，不声称支持全局未见靶点、五折轮换或研究留出。

对照为 `masked-response-shared-s01`，不是 exp007。各 run 独立核验其配置、checkpoint、预测和全部分数文件；输入及匹配 reference/anchors 从 `init-linear-s01` 固定来源逐项核验复制。使用冻结 cell-eval2 `5e64833518a6603a0301cbe28185d49c30f4a986` / vcc2026，保留原 raw gates、未定义值与负归一化分数。

组成与分布路线分别重算了四训练背景及 H1 输入 NTC 的原始算术矩；五份 NPZ 的 SHA256 均完全一致。每次重算也核验原细胞数、轴、标签和平均 logCPM。任务空间和生成器的差异没有混入数据选择变化。

## 下一轮资源决定

停止这三个具体配置的局部调参、线性/去 NTC 消融与额外种子。shared 继续作为控制。阴性仅限此次配置和 H1 范围，不否定非线性、VAE、Flow 或计数似然的一般价值。

下一轮新增两个整包探索槽位：`C-GENE-DECODER-PACKAGE` 优先研究基于基因功能与 NTC 状态、跨扰动基因和输出基因共享参数的条件解码器；`C-CELL-VAE-PACKAGE` 研究 NTC 条件的逐细胞生成模型及联合响应目标。前者扩大可建模的 target×gene 范围，后者改变单一均方误差/解析矩拟合的目标及分布学习方式。二者均不要求先过线性头，也不要求先完成所有先验消融；匹配真实/随机或无先验归因放在整包显出价值之后。

资源为两个探索槽位各一个预先冻结的完整配置；第三个槽位暂不占用，优先给达标方案做新背景确认。若两个新整包均未达标，第三槽转另一机制，禁止自动填成 H1 参数网格。它们目前是明确的 draft：完整预算、实际条件、源版本及代码仍需按节点 blockers 冻结，尚未训练。旧 GO 线性外推、当前小 MLP 的局部消融均不抢占这两个探索槽位。

这些路线依据文献卡 L05（GEARS 的功能/共表达先验）与 L09/L10（条件生成问题）以及本轮取舍形成待证伪假设。原论文不构成 VCC 2026 本地有效证据，也不把扩大覆盖本身当作性能增益。
