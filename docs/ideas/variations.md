**真正影响 perturbation response 的变量，不仅包括细胞状态，还包括实际干预强度、时间、环境，以及哪些细胞最终存活并被测到。** 另外，测序和数据分析会影响我们“看到的响应”，但不一定改变生物学响应本身。单细胞扰动研究已经明确区分了细胞类型、细胞状态、协同因子活性和干预效率等不同来源的响应异质性。([Nature][1])

先修正我前面的一处简化：**guide variation 和 batch variation 不能一概视为要去掉的噪声。** Guide 差异可能改变实际敲低强度；不同实验批次也可能意味着不同培养环境，从而真正改变基因依赖性。([PubMed Central (PMC)][2])

下面以 **CRISPRi / Perturb-seq → 单细胞转录组响应** 为范围，列出尽量完整的候选变量清单。这是结合外部研究整理的框架，**不是说 VCC 测量了这些变量，也不代表每个变量对每个靶基因都同样重要。**

## 一、细胞的遗传与谱系背景：它原本是什么样的细胞？

这类因素决定细胞具有怎样的调控结构和功能约束。

| 变量组        | 具体变量                           | 为什么可能影响响应                         |
| ---------- | ------------------------------ | --------------------------------- |
| **细胞身份**   | 组织来源、细胞类型、细胞谱系、细胞系             | 同一个基因在不同细胞中参与的功能、可用的协同因子和依赖关系不同   |
| **遗传变异**   | 胚系变异、体细胞突变、功能获得或缺失突变           | 某条通路可能已经异常激活或失活，改变再次干预的后果         |
| **基因剂量**   | 拷贝数变异、基因扩增或缺失、倍性、非整倍体          | 改变基因剂量、蛋白平衡和系统对进一步降低表达的敏感性        |
| **克隆与亚克隆** | 不同克隆的身份及比例、细胞系亚株               | 名称相同的细胞系也可能包含不同遗传背景的细胞            |
| **表观遗传背景** | 染色质开放性、启动子和增强子状态、DNA 甲基化、组蛋白状态 | 可能改变哪些调控关系可被启用，也可能改变 CRISPRi 的有效性 |
| **转录本结构**  | 使用哪个启动子、哪个转录起始位点、表达哪些异构体       | 同一个 gene symbol 不一定对应完全相同的功能性转录产物 |

这些不是单纯的“细胞标签”。已有研究发现，同一癌细胞系的不同亚株会发生遗传和转录差异，并表现出不同药物响应；CRISPRi guide 的有效性也与染色质、靶点位置和序列特征有关。([Nature][3])

**建模含义：不能假定“同一种细胞系＝完全相同的响应系统”。**

## 二、细胞当前的分子与生理状态：此刻它在做什么？

这部分最接近你说的 **真实 cell-state variation**。

| 变量组          | 具体变量                           | 需要关注的问题                    |
| ------------ | ------------------------------ | -------------------------- |
| **基线转录状态**   | 各基因表达量、表达比例、共表达模块              | 哪些功能程序正在运行？靶基因及相关通路是否活跃？   |
| **蛋白状态**     | 蛋白丰度、亚细胞定位、复合物组成、翻译后修饰         | RNA 相似时，实际执行功能的蛋白状态是否仍然不同？ |
| **转录因子状态**   | TF 活性、协同 TF、辅激活或辅抑制因子          | 敲低某个调控因子后，是否具备产生下游响应的其他条件？ |
| **信号通路状态**   | 受体激活、激酶活性、磷酸化、反馈调节             | 当前通路处于静息、激活、饱和还是反馈抑制状态？    |
| **细胞周期**     | G0/G1/S/G2/M、周期推进速度            | 干预发生在什么周期阶段？相关过程是否正在执行？    |
| **增殖与生长状态**  | 增殖速度、静息状态、细胞大小、总 RNA 和蛋白量      | 细胞对生物合成、分裂和能量供应的需求是否不同？    |
| **代谢状态**     | 糖酵解、氧化磷酸化、脂质和氨基酸代谢、能量及氧化还原状态   | 某条代谢途径被抑制后，细胞是否有替代能源或底物？   |
| **细胞器与蛋白稳态** | 线粒体状态、内质网应激、蛋白折叠、蛋白酶体、自噬和溶酶体状态 | 同一干预是否会跨过应激或功能失代偿阈值？       |
| **分化与激活状态**  | 干性、成熟度、分化阶段、免疫激活、EMT 等         | 细胞是否处于对该基因特别依赖的功能状态？       |
| **损伤与命运倾向**  | DNA 损伤、复制压力、衰老、凋亡敏感性、已有应激      | 细胞是否已经接近死亡、衰老或状态转换的阈值？     |

Perturb-seq 研究直接展示了细胞周期、分化、应激及协同调控因素与扰动结果的关系；蛋白水平差异也可以使遗传背景相同的细胞产生不同的死亡响应。这里列出的具体代谢和细胞器指标应作为**候选机制变量**，不能仅凭表达 signature 就认定其功能状态已被完整测量。([PubMed Central (PMC)][4])

**最容易被忽略的是：baseline RNA profile 是细胞状态的观测，不等于完整细胞状态。**

## 三、靶基因与当前系统的关系：这个细胞有多依赖它？

这一类不是额外的“背景标签”，而是 **target gene × cell state 的交互关系**。

| 变量组             | 具体变量                     | 为什么重要                              |
| --------------- | ------------------------ | ---------------------------------- |
| **靶点的功能性基线**    | 靶基因是否表达、蛋白是否存在、功能是否已失活   | 敲低一个活跃的功能节点，与进一步抑制一个已经失活的节点，后果可能不同 |
| **靶点所在通路的使用程度** | 通路活性、代谢通量、下游程序是否开启       | 不同细胞对同一通路的实际依赖不同                   |
| **功能冗余**        | 旁系同源基因、替代酶、平行信号通路        | 是否有其他分子能够补偿被抑制的功能？                 |
| **遗传互作**        | 合成致死、合成病弱、抑制性互作、已有突变背景   | 干预效果取决于其他基因是否正常工作                  |
| **复合物与网络结构**    | 蛋白复合物组成、亚基比例、上下游可用性、反馈回路 | 一个节点降低表达是否导致整个模块失效？                |
| **缓冲与补偿能力**     | 储备功能、反馈补偿、替代途径诱导、适应能力    | 系统能否吸收这次干预，还是会发生非线性变化？             |

例如，旁系同源基因的补偿能力可以解释部分基因为什么只在某些癌细胞系中必需；这种补偿还可能依赖补偿基因的表达剂量。([PubMed Central (PMC)][5])

所以，更准确的问题不是：

> 这个基因被敲低会怎样？

而是：

> **在当前细胞的功能需求、网络结构和补偿能力下，这个基因被敲低会怎样？**

## 四、干预的具体实现：实际上改变了什么、改变了多少？

**“输入一个基因名”只是任务接口，并不是完整的实验干预描述。**

| 变量组              | 具体变量                                           | 可能影响的环节                     |
| ---------------- | ---------------------------------------------- | --------------------------- |
| **干预对象**         | 靶基因、靶转录本、启动子、调控元件                              | 实际被改变的是哪个功能单元               |
| **干预方式**         | CRISPRi、CRISPR knockout、CRISPRa、RNAi、蛋白降解、药物抑制 | 降低转录、破坏 DNA、抑制蛋白活性不是同一种干预   |
| **实际干预强度**       | mRNA 敲低比例、剩余表达量、蛋白剩余量、残余活性                     | 相同靶点在不同强度下可能产生不同甚至非线性响应     |
| **细胞间效率分布**      | 完全响应、部分响应、未成功干预细胞的比例                           | 群体中实际可能混合了多个“有效剂量”          |
| **Guide 属性**     | guide 序列、靶点位置、与 TSS 的距离、结合效率                   | 影响靶向和转录抑制效果                 |
| **CRISPRi 执行系统** | dCas9/抑制结构域的类型、表达量、活性、稳定性                      | 同一个 guide 在不同执行系统下不一定产生相同抑制 |
| **递送与载体**        | 转导效率、感染复数、载体拷贝数、表达差异                           | 影响细胞实际接受的干预及实验负担            |
| **共同干预**         | 多 guide、多基因、同时用药、外部刺激                          | 可能出现协同、拮抗或遗传互作              |
| **非预期生物学作用**     | 脱靶、邻近基因抑制、递送相关应激                               | 会真正改变细胞，但不属于希望学习的纯粹靶基因效应    |

Guide 的染色质、位置和序列依赖性已有实验依据；Perturb-seq 研究也显示了干预效率和多重干预对响应解释的重要性。([PubMed Central (PMC)][2])

对当前比赛尤其要注意：附件说靶基因的 **on-target knockdown >80%**，但这**不等于每个单细胞都具有相同的敲低比例，更不等于蛋白活性都降低同样的比例**。附件没有提供这种逐细胞保证。

## 五、时间和历史：什么时候干预、什么时候观察？

| 变量组          | 具体变量                   | 需要区分的问题               |
| ------------ | ---------------------- | --------------------- |
| **干预后经过的时间** | 距转导、诱导、有效敲低开始的时间       | 观察到的是早期直接响应，还是晚期适应结果？ |
| **干预持续方式**   | 持续、短时脉冲、重复、撤除后恢复       | 相同终点时间并不代表相同的干预经历     |
| **分子响应速度**   | RNA 周转、蛋白周转、功能耗竭速度     | 转录被抑制之后，原有功能能够维持多久？   |
| **观察窗口**     | 采样时间、采样跨度、是否覆盖多个状态转换阶段 | 可能错过瞬时响应，或把不同阶段混在一起   |
| **既往处理历史**   | 之前的用药、刺激、营养限制、缺氧、恢复过程  | 当前状态可能保留历史影响          |
| **培养与传代历史**  | 传代次数、长期培养、冻融和恢复、克隆扩增   | 可能改变细胞群体及其遗传、转录状态     |

这不是抽象问题：Replogle 数据中，不同实验分别在转导后第 6、7 或 8 天采样；这些时间点不能仅因为都叫“某基因 perturbation”就被视为完全等价。长期培养导致细胞系演化也有直接研究支持。([Figshare Plus][6])

其中，“RNA 降低后原有蛋白还能维持多久”是根据转录抑制机制需要考虑的动力学因素，**并不是当前附件提供了相应测量值**。

## 六、培养环境和细胞间相互作用：它在什么环境下响应？

| 变量组         | 具体变量                        | 可能改变什么                |
| ----------- | --------------------------- | --------------------- |
| **营养组成**    | 葡萄糖、氨基酸、脂质、维生素、微量元素、其他代谢物   | 改变代谢途径的必要性和替代途径可用性    |
| **培养基与补充物** | 培养基配方、血清及其批次、生长因子、激素        | 改变信号输入、增殖需求和功能依赖      |
| **理化条件**    | 氧浓度、pH、温度、渗透压、CO₂ 条件        | 可能改变代谢、应激和信号状态        |
| **细胞密度**    | 接种密度、汇合度、培养期间的密度变化          | 改变接触依赖信号、静息状态和资源竞争    |
| **力学与培养结构** | 基质硬度、ECM 组成、黏附、机械张力、二维或三维培养 | 改变机械感知、细胞形态和相关调控程序    |
| **细胞间信号**   | 自分泌、旁分泌、细胞接触、共培养细胞组成        | 某个细胞的响应可能受到邻近细胞影响     |
| **培养过程**    | 换液频率、营养消耗、代谢废物积累            | 环境可能在干预过程中持续变化        |
| **非预期环境因素** | 污染、额外刺激物、培养操作造成的应激          | 应作为实验元数据排查项，而非直接假定不存在 |

这里的环境因素是**候选排查清单**，不是说每一项都已在 VCC 中被证明重要。直接证据包括：改变培养基组成能够改变 CRISPR 筛选得到的条件性必需基因；细胞密度也能改变某些基因缺失后的增殖表型。([PubMed Central (PMC)][7])

因此，**“培养批次”可能同时包含技术差异和真实生物学环境差异，不能只按 batch ID 整体抹掉。**

## 七、群体组成和选择过程：最后测到的还是原来那群细胞吗？

这一部分对预测 **400 个单细胞 profiles** 特别重要。

| 变量组        | 具体变量                  | 对观测响应的影响                  |
| ---------- | --------------------- | ------------------------- |
| **初始亚群组成** | 各细胞状态、周期阶段、克隆的比例      | 即使各亚群响应规律不变，总体响应也会随混合比例变化 |
| **差异增殖**   | 不同状态或克隆的增殖速度          | 生长更快的细胞在终点样本中占比增加         |
| **差异死亡**   | 对干预敏感细胞的死亡率           | 强响应细胞可能已经消失，终点只剩耐受者       |
| **状态转换**   | 分化、激活、衰老、周期阻滞或其他状态转换  | 干预既改变表达，也可能改变群体结构         |
| **实验筛选**   | 抗生素选择、分选、活细胞筛选、回收条件   | 决定哪些细胞有机会进入测量             |
| **抽样与捕获**  | 亚群捕获概率、细胞大小相关偏差、每组采样数 | 观测群体不一定完整代表培养体系中的真实群体     |

扰动实验可以改变细胞状态及群体丰度，而不同单细胞测量方法也存在细胞回收和组成差异；因此，群体组成变化需要与单个状态内部的表达变化分开考虑。([PubMed Central (PMC)][4])

举一个**假设例子**：

> 干预后，某基因的群体平均表达下降，可能是每个细胞都降低了表达；也可能是原本高表达该基因的亚群更容易死亡。

这两种机制能够产生相似的均值，却对应不同的单细胞分布。

## 八、测量、标注和分析：真实响应怎样变成数据矩阵？

**这一类主要影响 observed profile 或响应估计，不应直接当作生物学响应的决定因素。**

| 变量组           | 具体变量                                   | 主要风险                      |
| ------------- | -------------------------------------- | ------------------------- |
| **测量平台与化学体系** | 10x Flex、3′/5′测序、其他平台；单细胞或单核           | 相同生物学状态可能得到不同测量分布         |
| **基因检测机制**    | 探针覆盖、探针效率、捕获效率、可检测基因集合                 | 某些基因更容易或更难被测到             |
| **测序与计数深度**   | reads、UMIs、文库复杂度、测序饱和度                 | 影响稀疏性、低表达基因检测和统计精度        |
| **样本处理**      | 消化、解离、分选、固定、储存、处理延迟                    | 有些只影响测量；有些会在固定前诱导真实应激     |
| **污染与混合**     | ambient RNA、双细胞、多细胞、样本串扰               | 生成不属于真实单个细胞的表达模式          |
| **扰动标签准确性**   | guide 捕获率、guide 分配错误、多 guide 识别、样本标签错误 | 将表达 profile 关联到错误干预       |
| **计算预处理**     | 比对、基因注释、UMI 去重、归一化、变换、插补               | 改变数据尺度，可能引入或遮蔽差异          |
| **质量控制与校正**   | 细胞过滤、基因过滤、细胞周期回归、batch correction      | 可能误删真实响应或改变亚群比例           |
| **对照与统计设计**   | NTC 的选取、对照匹配、独立重复、样本数、差异检验方法           | 改变效应估计、置信度和显著性，而不是细胞本身的反应 |

平台差异、文库大小、ambient RNA 和解离诱导表达变化均有直接方法学或实验研究支持。Flex 本身使用探针式检测，因此也要考虑其检测体系，而不能把不同测序技术的 raw counts 直接视为同一种测量。([Nature][8])

还有一个与你前面的问题直接相关的区别：

> **18,400 个细胞是大量细胞观测，不自动等于 18,400 个独立生物学重复；46 个 NTC guides 也不自动等于 46 次独立培养实验。**

独立重复的单位取决于实际实验设计，而不是数据矩阵的行数。附件只说明了 guide 和细胞数，没有据此建立独立培养重复的结构。([Nature][9])

## 九、对于这次 VCC，哪些能知道，哪些只能推断？

这是把上面的清单转成模型设计时最重要的一步。

| 信息层级            | 当前能使用的信息                                        | 应怎样理解                 |
| --------------- | ----------------------------------------------- | --------------------- |
| **直接提供**        | NTC 单细胞表达矩阵、`context`、`ntc_id`、待预测的 target gene | 属于真正可用的输入             |
| **可以计算的观测特征**   | 表达均值、方差、检测比例、协方差、细胞亚群及其比例、计数分布                  | 是数据统计量，不自动等于真实生物机制    |
| **可以尝试推断的生物状态** | 周期、分化、应激、TF 或通路活性等                              | 属于代理表征，应保留不确定性        |
| **附件没有列为输入的信息** | 基因组、蛋白组、染色质、培养条件、靶向 guide 序列、逐细胞有效敲低、完整时间信息     | 不能假装已经知道，或保证从 RNA 中恢复 |
| **明确规定的实验背景**   | CRISPRi、10x Flex；所选靶基因满足文中敲低质量要求                | 有助于限定预测问题，但没有消除所有实验差异 |

上述输入字段和实验背景来自你提供的材料；“可计算”和“可推断”两行是建模上的区分。

### 最后，需要避免三个概念混淆

**第一，能解释 baseline variation，不等于能解释 perturbation effect variation。**
一个变量可能让所有表达整体偏高，但不改变该干预相对于对照的效应；也可能在 baseline 中很不显眼，却决定干预后的敏感性。这是预测 baseline 和预测响应差异两个目标之间的区别。

**第二，同一个变量在不同时间可以扮演不同角色。**
例如，干预前的细胞周期可能是响应条件；干预后的周期阻滞则可能就是干预结果。后者不能被一概当作 nuisance 回归掉。单细胞扰动研究也明确讨论了细胞状态作为响应条件、混杂因素或干预结果的不同角色。([Nature][1])

**第三，NTC 只能帮助约束部分背景变异，不能保证把所有因素分解干净。**
官方提供 `ntc_id`，允许分析 guide 间差异；但这并不证明 guide、培养批次、细胞亚群和其他隐藏变量已经被实验设计完全解耦。

因此，我建议把你的核心问题从“真实 state 与噪声能否分开”进一步精确为：

$$
\boxed{
\text{哪些变量决定生物学响应，哪些决定干预剂量，哪些决定被测到的群体，哪些只决定测量？}
}
$$

**模型不必恢复所有真实变量才能有用，但必须避免把真实响应条件当噪声删除，也避免把实验与测量特征误学成可泛化的生物学规律。**
