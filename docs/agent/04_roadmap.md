## 0. 原则

1. **先有可信的基线和评测，再做单变量实验，按“预期收益 / 成本”排序。**
   - 第 0 轮：只建数据、评测器、基线和噪声阈值，不比较新方法。
   - 第 1 轮起：每个实验相对一个固定对照只改一处。
   - 每轮的胜者合成一个整包，再对整包做“去掉一个组件”的消融，用于归因。
2. **方法顺序按 Q9：先迁移、后学习、并行大模型。** 所有迁移参数都在公开数据的 LOCO 上拟合，见 Q3。
3. **选型依据按 Q7**：日常看 PDF 的 H1 测试集；晋级前再看 2–3 个留出背景；阈值用 k·SD。
4. **每轮开始前用 grill-me 与你对齐**（Q8）。本文的轮次和实验是候选清单，不是自动执行的队列。
5. **收益锚点**：上表 5 个榜单条目的六项构成（scaled，2026-10-04 13:13 UTC 抓取）。

**由上表得出的判断**【推断】：
- 从 0.05 到约 0.16，主要靠 PDS（0.38→0.68）和 Fidelity（−0.20→−0.02）。这两项分别对应多源同靶监督，以及去掉共同响应后不再“到处制造假 DE”。
- 从约 0.16 到约 0.27，主要靠 MSE（0.05→0.41）和 Reach。这对应幅度校准，以及把效应限制在目标背景可实现的方向上。
- 再往上，需要更准的逐靶响应和 DE 结构：NMAE、Fid、Jac 三项都要上去。

### 第 1 轮：学习化多源迁移（10/07–10/11）

单变量链：B0 = Shared（K562），每步只加一处，前一步的胜者作为下一步的对照。

#### E1 去模板：减去每个源的共同响应

- **假设**：我们的 raw 表达误差为 4.5–7.9，主因是把 K562 的共同（系统性）响应原样加到了每个靶点上。按 KnowGraph `PAP-VCC` 的推导，模板误差要被计 P 次。按训练靶拟合并减掉源模板后，raw 表达误差会降到 ≤1.2，Fidelity 从约 −0.2 升到约 0，PDS 不降。
- **改动**：Δ_src(t) → Δ_src(t) − m_src。m_src 是该源训练靶响应的均值，排除各靶自身基因；扣除比例 γ 在 LOCO 上拟合，γ ∈ [0, 1]。
- **对照**：B0。
- **成功判据**：
  - L2：raw 表达误差下降 ≥30%；
  - Overall 提升 > 阈值；
  - L3 最差背景不降。
- **预估成本**：开发 2–3 小时，计算约 1 小时。
- **收益 / 成本**：高 / 低。**优先级 1。**

#### E2 幅度收缩

- **假设**：源与目标响应的余弦相似度多半低于 0.5，此时“照搬幅度”的收益为 (2ρ−1)‖d‖²，是负的（KnowGraph `PAP-VCC`）。在 LOCO 上拟合一个全局收缩 α，以及 bulk 空间与均值 CPM 空间各自的 α（AtlasShift 用的是 0.3/0.6），可以降低表达误差和 NMAE，且 PDS 不变，因为 PDS 用的是余弦。
- **改动**：Δ → α·Δ，α 在 LOCO 上拟合。
- **对照**：E1 的胜者。
- **成功判据**：同 E1，并且 PDS 变化在 1 SD 以内。
- **预估成本**：开发 1–2 小时，计算约 1 小时。
- **收益 / 成本**：高 / 低。**优先级 1。**

#### E3 多源监督：用所有已标准化的数据源，按 LOCO 学源权重

- **假设**：Xaira 两个背景覆盖全部 300 个官方靶点、近乎全基因轴，深度也接近官方。加上 K562_essential、RPE1、Jurkat、HepG2 等源，并学习源权重后，PDS 能从约 0.38（官方 scaled）升到约 0.65–0.70，也就是 AtlasShift 的水平；同时“无源监督的读出”大幅减少。
- **改动**：
  - 每个靶点的 Δ 改为多源加权平均，权重 w_s 在 LOCO 上拟合，用非负、和为 1 的约束；
  - 测量掩码按源处理；
  - 缺测不补零。
- **对照**：只用 K562 的 E1+E2 最优版本。
- **成功判据**：
  - L2：PDS 与 Overall 提升 > 阈值；
  - 按“源支持”分层后，各层不降。
- **预估成本**：开发 0.5 天，计算约 2 小时。
- **收益 / 成本**：很高 / 中。**优先级 1**（依赖数据包第 2 批）。

#### E4 计数发射器（响应固定，只比发射器）

- **假设**：同时匹配均值 CPM（对应 DE 指标）和 pseudobulk（对应表达误差），并让细胞间的噪声与真实 NTC 匹配，可以改善 Reach 和 Fid，且不损害表达误差。参照：AtlasShift 加入噪声匹配后，从 0.155 升到 0.180。
- **改动**：三选一比较——
  - 群体校准发射器（当前）；
  - 双矩匹配的整数分配；
  - 双矩匹配再加噪声匹配。
- **对照**：群体校准发射器，用同一个响应输入。
- **成功判据**：
  - L2：DE 类三项的平均提升 > 阈值；
  - 零响应输入时，伪 DE 不超过 NTC 抽样范围（L0）。
- **预估成本**：开发 0.5 天，计算约 1.5 小时。
- **收益 / 成本**：中高 / 中。**优先级 2。**

#### E5 靶点自身敲低与启动子邻近校正

- **假设**：官方靶点的敲低 ≥80%，而我们的预测残留为 65%–68%。把靶点自身表达压到约 20% 以下，并对启动子 5 kb 内的邻近基因做衰减校正，会给 LFC 和 DE 带来小幅收益。这两处对 PDS 无直接作用：PDS 排除整个 panel 的靶基因。
- **改动**：两个开关，分别做 2×2。
- **对照**：E4 的胜者。
- **成功判据**：L2 提升 > 阈值；如果没有提升，就只保留不伤分的那个。
- **预估成本**：开发 2–3 小时，计算约 1 小时。
- **收益 / 成本**：低 / 低。**优先级 3。**

#### I1 整包 C1 与归因

### 第 2 轮：学习层（10/11–10/16）

以 C1 为对照，单变量叠加。

#### E6 目标背景 NTC 子空间投影 / 平滑

- **假设**：真实响应的主要部分落在目标背景自身 NTC 的主成分子空间里（KnowGraph `PAP-F-CONTROL`：从 control 看得到模板；参赛者 #19，0.267，自述用了类似做法）。把预测效应投影到这个子空间，并对子空间以外的部分做收缩，可以显著提升 MSE 和 Reach。#19 的 MSE 是 0.41，AtlasShift 是 0.05。
- **改动**：用目标背景的输入 NTC 做 PCA，子空间维数 r 和子空间外的收缩系数 β 都在 LOCO 上拟合。
- **对照**：C1。
- **成功判据**：
  - L2：表达误差和 Overall 提升 > 阈值；
  - L3：最差背景不降。
- **预估成本**：开发 0.5 天，计算约 2 小时。
- **收益 / 成本**：很高 / 低中。**优先级 1。**

#### E7 背景自适应的源权重

- **假设**：目标背景与哪个源更像，可以从 NTC 表达谱推断。参赛者报告 A/B/C 更接近 Flex 化学测的 H1/CD4。按相似度学习的权重，比全局权重更稳。
- **改动**：w_s = softmax(−λ·D(NTC_target, NTC_source))，λ 和距离定义在 LOCO 上拟合。
- **对照**：C1 的全局权重。
- **成功判据**：L3 的平均和最差背景都提升 > 阈值。
- **预估成本**：开发 0.5 天，计算约 2 小时。
- **收益 / 成本**：中 / 低中。**优先级 2。**

#### E8 逐靶 / 逐基因收缩（经验贝叶斯）

- **假设**：多个源之间不一致、细胞数少的靶点或基因，应该向 0 收缩。这样能降低表达误差和 NMAE，提升 Jaccard。
- **改动**：收缩强度由源间方差和 n 决定，超参数在 LOCO 上拟合。
- **对照**：C1 + E6 的最优版本。
- **成功判据**：L2 提升 > 阈值。
- **预估成本**：开发 0.5 天，计算约 1.5 小时。
- **收益 / 成本**：中 / 低。**优先级 2。**

#### E9 背景响应强度标定

- **假设**：效应幅度的主成分与对照表达相关（外部报告的相关系数为 0.46–0.81，见 01 §1.4 所引 Jin-Hong Du 报告）。从目标背景 NTC 的特征（增殖、应激、深度）预测每个背景的整体幅度系数，可以减少系统性的幅度偏差。
- **改动**：幅度系数 s_c = f(NTC 特征)，f 用线性模型，在 LOCO 上拟合。
- **对照**：前一个胜者。
- **成功判据**：L3 提升 > 阈值。
- **预估成本**：开发 0.5 天，计算约 1.5 小时。
- **收益 / 成本**：中 / 中。**优先级 3。**

#### E10 未见靶点和低覆盖靶点的回退模型

## 5. 自进化闭环怎么运转

每一轮按“提出假设 → 对齐 → 实验 → 评估 → 记录 → 下一轮”走一遍：

```
┌─ 1 提出（我） ─────────────────────────────────────────────┐
│  读：Ledger、冠军表、上轮诊断、与参考条目的逐项差距、          │
│      KnowGraph 中相关节点（一跳）、失败记录                    │
│  出：≤3 个假设，每个写明：预测的方向和幅度（预登记）、改动、    │
│      对照、判据、预算、收益/成本                               │
├─ 2 对齐（grill-me，一次一问） ──────────────────────────────┤
│  你决定：做哪几个、预算多少、是否提交官方、是否改协议或数据    │
├─ 3 执行 ──────────────────────────────────────────────────┤
│  登记一个批次节点（冲刺契约），冻结配置和 seed，并行跑         │
│  L0 → L1 → L2 → L3；L1 没通过的候选不进入下一级                │
├─ 4 评估 ──────────────────────────────────────────────────┤
│  配对效应和 k·SD 阈值；raw 六项；两个无信息下限；分层；       │
│  冠军—挑战者替换                                              │
├─ 5 记录 ──────────────────────────────────────────────────┤
│  简短 REPORT，Ledger 一条结论（支持/不支持/证据不足 +          │
│  下一步 + 重开条件），更新冠军表；commit                      │
└─ 6 下一轮：用“预测 vs 实际”的偏差修正假设生成 ─────────────┘
```

**防过拟合与防钻空子**

- H1 只用于日常筛选；替换冠军必须过 L3。
- 验证榜每天最多 1 次，只用来校准，并且累计记录每次提交的目的。
- 每个假设都要在运行前写下预测。预测错误的类型会进入记忆，用来调整下一轮的假设。
- 每轮抽查改动的代码，确认没有利用评测器漏洞，例如读取评分 NTC、按测试靶点调参。
- 在 L3 背景上，不复用 H1 上调出的超参数。所有参数只在训练背景的 LOCO 上拟合。

**停止规则**

- 一个方向连续两轮没有超过阈值，就停止，换机制。
- 每轮最多 3 个问题。
- 计算预算在对齐时确定。
- 10/20 起只做冻结和彩排；11/04 后不再改模型。

**记忆**

- Ledger：每轮一条结论。
- 冠军表：当前最好配置、各级分数、对应的 commit。
- 失败记录：哪些做法因为什么没有效果，避免重复尝试。
- 03 中的对齐决策：除非你改，否则一直有效。
