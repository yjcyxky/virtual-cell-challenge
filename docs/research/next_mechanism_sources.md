# CellOT 与 Arc State：下一轮机制来源核查

核查：2026-09-28。已执行 `research.py status`；当前条件细胞 VAE 由主任务完成。本页仅为外部来源与待检验设计，不登记或评价本地方法有效性；未读取模型分数，未下载权重或启动训练。共同边界为四背景训练、H1 仅 input NTC、18,533 官方输出轴、来源测量掩码及 DAG 冻结的 cell-eval2；详见[数据基础](dataset_foundations.md)及[机制搜索规则](../RESEARCH.md#机制整包搜索与资源分配)。

**完整基因轴与缺测。** CellOT 的 AE／运输要求一致坐标，原实现并未直接解决跨来源测量掩码；需要训练内拟合、掩码重建及完整轴 decoder，不能将缺测补为真零。[CellOT 数据实现](https://github.com/bunnech/cellot/blob/522d2b953da8ad244fcf36f64521487fdf763788/cellot/data/cell.py)。State 的 HVG 示例只作输入表示，不能据此缩减最终输出；SE 按蛋白嵌入词表映射基因并保留有效基因掩码，但这不自动保证 ST 的监督／分布距离忽略缺测。两条路线都须逐背景在实测坐标上计算训练损失，并单独规定全轴非负整数 counts 的解码、文库深度及未监督基因策略。[SE loader](https://github.com/ArcInstitute/state/blob/9bbfe78a434a55205e4de834e1ea99f85f7a3add/src/state/emb/data/loader.py)、[ST 用法](https://github.com/ArcInstitute/state#state-transition-model-st)。

**预训练重叠与本地资产。** CellOT 可从训练折内数据拟合，无必须复用的预训练权重。State 正式摘要称 SE 使用 1.67 亿细胞；本地 [SE 配置](../../models/arc_se600m/config.yaml) 标记 scBaseCount／CELLxGENE／Tahoe，但没有可核验的完整 accession 清单，不能证明排除了 H1 或四个来源研究。ST 的 Replogle-Nadig 研究涉及 K562、RPE1、HepG2、Jurkat；公开权重不能直接成为这些背景轮换留出的干净对照，且作者配置名为 `replogle_nogwps_v2`，不等同于本地 K562 GWPS。需按具体 checkpoint 核对训练划分。[作者划分](https://github.com/ArcInstitute/state/tree/9bbfe78a434a55205e4de834e1ea99f85f7a3add/state_preprint_toml_files/replogle_tomls)。本地 [SOURCE](../../models/arc_se600m/SOURCE.json) 登记的两个 safetensors 都是 SE 资产，**没有据此确认 ST 权重**；只读 tensor header 可见 `pe_embedding`，仍需补齐可核验的 gene→row 映射与加载版本。现行 CLI 另支持 `protein_embeddings.pt`／checkpoint 内词典／配置路径三种来源，不能直接假定旧 safetensors 可加载。[SE 模型卡](https://huggingface.co/arcinstitute/SE-600M)、[加载代码](https://github.com/ArcInstitute/state/blob/9bbfe78a434a55205e4de834e1ea99f85f7a3add/src/state/_cli/_emb/_transform.py)。可复用本仓库的 [cell pool／测量映射](../../src/vcc_mechanism/cell_inputs.py)、[训练状态保存](../../src/vcc_mechanism/learning.py)和[官方执行／评估链](../../src/vcc_mechanism/runner.py)，复用须冻结来源，不能修改活动 run。

**待检验整包。** ① 训练内掩码 AE＋已见靶点 ICNN 运输＋全轴计数 decoder，检验最小位移先验能否迁移到 H1；全局未见靶点需显式先验编码和条件运输扩展。② 从头训练 ST 的 NTC 集合交互＋分布目标＋全轴 decoder，SE 可作为冻结输入分支。真正机制变化分别是 **OT 耦合／运输目标**与 **细胞集合交互／分布学习**；只把旧头输入换为 SE 是表示变化，不等于运行 State ST。两者均只能先归因于整包，不预判赢家。

**明确落地前置：** 先完成一次不拟合模型的接口核验，固定作者代码／权重来源与允许训练样本，证明每来源实测 mask、18,533 轴、H1 仅 input NTC 和 counts 导出可贯通，同时测量一个真实尺寸前后向的显存／耗时以冻结完整训练预算。SE 词表或重叠清单不足时，先采用训练内表示的 ST／OT 整包；复用新权重时记录来源、哈希与训练暴露。之后登记比较与晋级／停止条件再训练；**不要求先在线性头上获胜**，也不把接口预检当完整实验。
