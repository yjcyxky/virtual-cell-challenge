# VCC 2026 数据约束与本地能力评估设计

2026-09-30，根据用户对研发方向的修正，从实验观测过程和任务约束重新定义下一轮。目标是让训练监督、计数生成和本地评价回答同一个问题，并在提交前证明模型包含可迁移的扰动特异信息。本文是设计与来源说明；执行队列和状态以 Method Space、Experiment DAG、Evidence Ledger 为准。没有新增训练、评分结果或有效性结论。

## 观测对象与可辨识边界

模型预测的是特定 CRISPRi 实验条件下、被捕获并保留下来的细胞表达快照。它同时受靶点、敲低剂量、背景状态、采样时间、存活选择、测量化学及深度影响。只有五背景、三来源研究，背景和 assay/时间/效应器混杂，不能仅凭当前数据把这些贡献独立识别。固定每靶细胞数消除了可用细胞数作为丰度表型的解释，未消除增殖停滞、应激及存活选择的转录后果。[五背景事实](dataset_foundations.md)

用两个明确的统计空间描述响应：

- 表达谱：`b = log1p(50000 * sum_cells(counts) / sum_all(counts))`，`delta_bulk = b_pert - b_NTC`。
- DE：逐细胞 `CPM = 1e6 * counts / library`，官方 Wilcoxon、对照表达过滤、BH 和算术均值 LFC 全部调用冻结 scorer。

`mean(log1p(CP10K))` 与上述两者都不同。令细胞组成是 `p_i`、深度是 `L_i`，bulk 使用 `sum(L_i*p_i)/sum(L_i)`，DE 的均值使用 `mean(p_i)`；两者差异还取决于深度与组成的关联。一个任意的 log 空间 delta 不一定对应可实现的计数组成，逆变换后的归一化和取整会改变它。生成器应记录请求响应与最终 counts 再测得响应的差异，而不只检查形状与整数性。[官方指标定义 S1]

## 用户提出的 17 项检查及适用边界

| 项 | 纳入下一轮的要求 | 必须保留的边界 |
|---|---|---|
| 1 靶基因自身 | 主要响应损失和能力报告关注评分允许的下游基因；保留独立的敲低质量诊断 | 官方 PDS 排除整个 panel 的靶基因，其他五项排除当前靶点。自身下降没有直接分项奖励，但自身 counts 仍参与归一化，不能任意置零或删除该输出列。[S1] |

| 3 敲低效率 | 优先以训练数据中的 guide/批次/靶点汇总估计效率及不确定性；比较可靠性权重、条件化与有限过滤 | 靶点低表达或缺测记 unknown；弱下游响应不能自动判为失败敲低。预测端效率未知时须估计或边缘化，不能读取留出扰动表达；直接按大响应筛样本会改变目标人群。[L02](literature_foundations.md#l02--有效扰动识别的价值及选择偏差mixscape) |
| 4 整数生成 | 最终输出非负、有限、整数 counts；生成器显式控制文库大小、零比例与生物变异 | 神经网络内部可输出连续组成/效应/分布参数；不要求不可微的整数输出头。随机取整不保证逐行总量，单纯多项式采样也不保证真实过度离散。[S1] |
| 5 深度和细胞数 | 分离技术采样深度、RNA 含量与细胞状态；从许可目标 NTC 建立生成时深度依据；essential 性使用版本化外部先验 | CPM 对齐不能代替稀疏度与测量化学对齐。400 个细胞不提供丰度/存活率证据，源数据细胞少也不能直接解释为 essential。[S1、S2] |
| 6 稀疏长尾响应 | 强弱响应分层，报告预测/真实 DE 数、假阳性、漏检、符号及置信排序；低可信响应允许收缩 | 近零是弱响应的候选预测，不是把弱响应标签删除。Jaccard 看集合，reach 在真实显著池中评估预测置信排序的方向可靠深度，两者不能混称“检出哪些基因”。[S1] |
| 7 通路诊断 | 固定输出完整响应和去模板响应的 Hallmark/已许可程序恢复、方向、误差、覆盖及有效扰动数 | 通路相关性受共同程序和重叠基因集影响；不是机制发现，也不替代六指标。作者代码确认有此诊断，不据此认定某模型在本地通路上更好。[S5] |
| 8 DepMap 对齐 | 优先建立版本化 DepMap 特征到实测响应的监督 Ridge/低秩基线，配同输入小 MLP | KO fitness 与 CRISPRi 表达不是同一观测量；先验须监督对齐。论文的容量结论不构成本项目“线性已饱和”的结论。[S3、S4] |
| 9 NTC 主成分 | 在训练内检验 PC 与周期、深度、RNA 含量、批次的关联；检验 NTC 到模板的跨背景映射 | PC 不预先命名为周期，也不自动回归掉；覆盖模板方向不等于能预测未见背景的方向、强度或扰动系数。18,400 个 NTC 不是 18,400 个背景。 |
| 10 功能邻居 | 用留出靶点的监督响应预测检验外部先验的增量，原始余弦 kNN 留作对照 | 相似性不是调控关系；“原始先验与残差相关近零”仅作为图谱的外部研究提示，本次未独立复算。 |
| 11 应激模板 | 同时报告模板方向、强度、去模板残差和增殖/应激程序；模板须随背景及 panel 检查 | 论文模板与官方 oracle 均值基线不严格相等，23%–65% 不能搬为 VCC 常数；旧 r3 数字不能认证 r4 构建，也不能直接反推模板能量。[r4 边界](r4_anchor_audit.md) |
| 12 快照与机制 | 允许间接、邻近及状态介导的真实响应；TF/网络范围限制作为候选先验接受 LOCO 检验 | 预测成立不证明因果链；不能以“非直接靶基因”删除实测响应。 |
| 13 响应稳定性 | 先用训练背景和分半/guide 重复估计稳定性及测量噪声，再检验可用输入能否在内层背景留出中预测稳定性 | 低细胞数、缺测和强度差异可制造不稳定；无足够背景支持的靶点保持 unknown。外层真值分型不能作为 MoE 门控输入。 |

| 15 训练与目标口径 | 建立原始训练观测与任务匹配评估视图；高深度数据可在可行范围内按 UMI 抽稀，评估记录每靶真实 n | 20k 是中位数，不是每行强制 20k；低深度不能补出真实信息。训练可使用更多真实细胞并平衡任务权重；不足 400 的 reference 不复制，单列功效与覆盖。[S1、S2] |
| 16 HVG 和完整轴 | HVG/PCA 只作内部表示，完整官方轴输出、每源测量 mask、未监督输出策略单列 | 全部来源都缺测的基因响应不能仅靠增加 decoder 参数识别。HVG/PCA 拟合排除外层扰动标签；目标 NTC 适配预先声明。 |
| 17 基线与响应 | 以输入 NTC 提供的经验基线为起点，学习响应及必要的边缘分布变化 | 输入 NTC 与评分 NTC 是独立样本，前者不是后者的精确 bctrl。均值正确不足以保证四个 DE 指标正确；NTC 变异也不能随意删去。[S1、S2] |

尤其需要审计**归一化分母**：公开矩阵有预筛基因，各背景保留列不同；在已测子轴内归一化得到的是不同条件组成。应记录 native 矩阵总计数、官方已测子轴总计数、可靠的原始 UMI 元数据及其关系。不能把缺失基因补零就声称恢复了全转录组 CPM，也不能将已测子轴的 20k UMI 当作完整官方轴的 20k。训练表示可评估共同测量支持上的校准，但正式输出/评分不能默认缩为交集。

## 数据和生成规则

硬约束来自冻结输入与提交协议：基因顺序、context/靶标签、规定细胞数、有限非负整数计数、非空文库、计数上界、测量 mask 和信息边界。CLI 的 400 行提交要求与 generic scorer 可接受的细胞数范围分开记录；由固定 CLI 和本地官方文件验证。[S1、S2]

实验合理性采用有条件的诊断边界：深度分位数、检出基因数、零比例、均值方差关系、主要程序与异常细胞比例，同时检查它们的联合关系。边界由训练来源及许可目标 NTC 的重抽样估计，按 assay、深度与响应强度分层。真实扰动可改变 RNA 含量、周期和稀疏度，因此不能把所有预测强压回 NTC 的同一包络。

计数生成采用显式的 `响应参数 + 目标 NTC 经验状态 + 深度机制 -> counts` 接口。逐行总量有约束时使用守恒的计数分配/取整；生物变异由经验状态或经过校准的分布承担，不能仅靠额外采样噪声替代。先用零响应、已知可实现响应和独立实测子样本检查生成保真度，冻结后再比较响应模型。模板重采样、Gamma-Poisson 或更复杂生成器均是候选，当前设计不认定任何一个必然正确。

## 本地能力评估的交付标准

### 数据支持和可评分性

每折输出背景/研究/guide/批次/靶点/读数覆盖、真实细胞数、深度、敲低可靠性和缺失原因。建立主任务匹配视图和稀缺样本敏感性视图，后者不能声称达到 400 个真实细胞的检验功效。真实/预测 n 的策略分别冻结；不能增加生成细胞或复制 reference 来调显著性。anchor 退化和指标未定义如实报告。

### 生成器是否引入假响应

对独立 NTC 做输入重采样与零响应生成的配对比较，使用官方 DE 路径；报告伪 DE 集合、符号、LFC 和分布漂移。与重复的真实 NTC 对 NTC 抽样范围比较，不能把“必须零个显著基因”作为不可能满足的要求。对可实现的已知响应检查计数逆映射前后的 bulk/CPM 效应和 DE 保真度；oracle 条件仅用于生成器诊断，不作为可部署模型成绩。

### 模型是否携带靶点信息

每次正式模型评价配 zero-delta、来源均值、来源逐靶迁移（仅已见靶可用）、模板-only、冻结预测后打乱靶标签等诊断。官方 oracle baseline 只在评分侧建标尺。正式比较保存六项 raw、normalized、Overall、截断前表达误差、指标有效数及逐靶 DE 明细。

同时检查去模板残差：对训练内定义的模板子空间，将真实与预测响应投影到其正交补后评价。另可给出仅评分侧估计的目标模板诊断，须标为 oracle、使用预定分割并禁止回流模型。**减去固定 centroid 与移除模板方向不等价**；对每条通路跨扰动求 Pearson 时，减去同一个常数甚至不会改变相关性。必须同时保留方向投影后的恢复、误差和幅度，识别只学到 `a_target * stress_direction` 的模型。

固定通路报告包括 stress/p53、cell cycle/proliferation、免疫/信号和其余已覆盖程序的原始及残差恢复；冻结基因集版本、符号映射、测量覆盖、最少可测成员和无效条件。通路间不当作独立重复。强弱响应/效率分层只用于评分解释，不能拿外层真值分层标签给模型路由。

### 能力是否迁移

五背景 LOCO 的 context-seen 与全局靶点留出的 joint-OOD 分开；附三来源研究留出。外层标签不参与 HVG/PCA、响应稳定性、template、权重、超参或停止条件拟合。H1 及已用于选择的本地背景是开发证据；新一轮反复查看其他折后也不能继续叫独立测试。逐背景/研究报告配对效应，训练 seed 与生成 seed 分开；细胞 bootstrap 不增加生物背景数。

提交条件是：硬约束通过；空响应及已知响应诊断没有超出预定统计容差的系统漂移；相对可用信息相同的简单基线和靶标签置乱有超出预定波动的收益；去模板扰动特异信号及通路诊断支持该收益；完成预先冻结的跨背景确认。数值容差从训练/校准折确定并在候选正式评分前冻结。不能把“本地分数接近榜单”用作门槛，榜单只用于冻结方案后的外部核查。

## 下一轮资源顺序

1. **数据与生成条件**：形成可重建的深度/效率/测量覆盖视图和计数生成契约；完成实测 null、可实现效应与低样本支持诊断。只读数据审核和校准是有明确产出的工作，不是无限协议审计。
2. **本地能力评估**：在既有官方评分接口上补齐上述诊断并贯通实际 LOCO、S3 与 S4；实现与第 1 项可并行推进。候选模型使用同一冻结协议，避免重新定义“通过”。
3. **DepMap 监督对齐基线**：使用相同数据/生成器，首轮对比响应对齐 Ridge 和小 MLP，包含无先验、等维匹配随机/靶点映射打乱先验，以及原始余弦 kNN 诊断；先验 PCA 仅训练靶拟合，缺先验与缺输出监督分别报告。NTC 到模板和稳定性门控保持独立假设。线性基线的成功不是以后启动完整复杂机制的通用前置。

本轮为设计重排，训练与 leaderboard 提交预算为零。执行阶段先冻结一个数据/生成校准批次和一个 evaluator 验收批次；DepMap 首轮每个外层背景 × context-seen/joint-OOD × 方法 × seed 一个独立完整拟合，禁止自动网格。具体 panel、完整超参、迭代结束条件、生成次数、硬件时长和晋级/停止门槛须在对应 run 的 expected_config 中冻结，当前尚不具备启动条件。集合模型 draft 保留，暂不分配训练预算；完成能力评价基础后可作为独立整包探索，毋须等待所有模板/MoE 故事验证。
