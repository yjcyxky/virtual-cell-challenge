## 数据处理

### 原始观测与任务视图分开保存

1. **主档保留全部有效原始整数 counts。** 保留 study、context、assay、guide、batch、物理细胞身份、靶点及测量掩码。沿用冻结映射、H1 物理去重和 input/score NTC 隔离；基础正确性排除与可选 QC 分开。
2. **训练用所有允许的真实细胞估计统计量。** 先限定外层背景和全局靶点分区，再读取/拟合表示、标签统计和响应模板。默认先背景等权、再在背景内靶点等权，任务权重为 `1 / (训练背景数 × 该背景训练靶点数)`；组内更多细胞提高统计精度，不直接放大任务权重。该权重是资源与目标人群选择，尚未证明性能最优。
3. **高深度抽稀仅形成独立任务视图。** 沿用当前输入 NTC 决定的固定抽稀率进行二项抽稀；原始主档不覆盖。当前 H1 的 native 抽稀率约 0.3667，其余背景为 1。这只是可行的局部近似，不声称补齐 assay 差异或完整官方轴 20k 深度。低深度来源保留实际深度，禁止通过复制分子或细胞补真值。
4. **真实 reference 每靶使用至多 400 个唯一细胞。** 不足 400 则保留真实 n；训练统计可以使用更多细胞。主评分预测固定 400 细胞，另做 n 匹配的生成子样本诊断。训练采样、reference 采样与生成采样各自记录随机种子。

20k 是目标分布的中位深度，不是每个细胞的行总量要求。目标推断优先使用许可 NTC 的经验深度及状态联合分布；扰动是否改变该分布属于模型假设。额外 RNA 含量变化与技术深度无法仅靠 CPM 完全分辨。

### 敲低效率与批次

**默认保留效率未知与弱响应任务，不启用按效率硬筛选。** 现有 guide×batch 估计大量为 unknown，不能作为失败敲低的代理。

下一版剂量估计先用同批次输入 NTC 校准，再在 guide/target 层汇总或部分汇聚，保留不确定性、guide 间冲突与可测性。source 端可把估计剂量及 uncertainty 用作训练协变量或软权重候选；推断端只能使用可获得特征预测剂量或对其分布边缘化。禁止把留出扰动自身表达给模型，也不能直接除以小效率把弱效应放大。

批次、周期、应激与 guide 差异保留为元数据或诊断项。当前不对监督真值默认做 Harmony/ComBat、插补、去应激或回归周期；这些变换会改变本任务要预测的观测分布，若用于内部表示须训练内拟合并单独验证。邻近基因及间接响应保留。PDS 排除整个面板的靶基因，另五项排除当前扰动自身靶基因；响应监督相应掩码。靶基因 counts 仍参与合法文库与归一化，不能先删列再计算分母。

## 标准化

### 两种统计量对应两类评分

令 M 为该来源真实测得的官方基因集合，x 为原始 counts。表达谱侧先汇总细胞，再归一化和取对数：

```text
B[t,g] = log1p(50000 × sum_i x[t,i,g] / sum_i sum_h∈M x[t,i,h])
Delta_bulk[t,g] = B[t,g] − B[input_NTC,g]
```

这是默认的群体响应监督空间。逐细胞 log1p 后再求平均可以是内部特征，但不等于这个 B，也不等于官方噪声修正后的表达误差。

DE 侧保留原始细胞矩阵，让官方实现计算逐细胞 CPM、Wilcoxon、BH 及算术均值 LFC；CPM 的分母仍是本次评分的实测轴，绝不换成 bulk 均值。`target_sum=1e6`、控制均值门槛 5 CPM、BH 0.05 等沿用冻结配置。辅助保存 `mean_CPM`、方差、检出率，便于诊断单细胞分布。两条正式评分路径都从**同一最终 counts**出发。[官方配置](https://github.com/ArcInstitute/cell-eval2/blob/5e64833518a6603a0301cbe28185d49c30f4a986/src/cell_eval2/configs/vcc2026.yaml)

模型输入 NTC 与评分 NTC 是独立样本。上式训练/推断使用 input NTC；官方评价以 score NTC 为统一参照。不能把后者当成已知模型基线。

### 测量范围必须进入观测映射

**不能把不同 M 下的 CP50K 或 CPM 当作同一个完整轴坐标直接拼接。** 背景内扰动减 NTC 可以减轻部分来源差异，不能保证消除由扰动引起的组成分母变化。

对输出完整轴期望 counts 的模型，采用以下观测契约，再与该来源真值比较：

```text
预测完整轴 counts/均值 → 限定到 M → 在 M 内重新求和归一化 → 对应 bulk/细胞统计损失
```

例如完整轴群体组成预测 p 在来源 M 的可观测组成是 `p[g] / sum_h∈M p[h]`。单细胞路径要先逐细胞投影，不能用一个 bulk p 代替各细胞 CPM。仅把缺测维度的 MSE 权重置零、却使用不同分母，仍然不满足这个契约。

这是一项观测一致性要求，不是已验证的新模型。Ridge 等直接输出来源归一化 Delta 的实现也必须声明其分母/解码假设；当前缓存的 bulk Delta 不能宣称已完成跨 assay 对齐。共同测量支持可用于表示拟合和诊断，但正式输出保持 18,533 维，本地评分保持各背景实测官方轴。

始终记录 `native_library`、`measured_library`、可用的 `metadata_UMI` 三种深度。metadata UMI 用于测量审计；定义不一致时不自动充当所有来源统一分母。HVG/PCA 仅用于内部降维，按 source 训练数据及预声明允许的目标 input NTC 拟合。未被任何训练来源测得的输出单列为不可识别，保守的零 Delta 回退须单列覆盖；不能把缺测标签补为零监督。

## 计数生成接口

当前唯一确定的选择是**停止把逐组 IPF 强制匹配列总量作为已验收默认**。其抽样波动抵消与四背景重建误差已有本地记录。下一候选是在输入 NTC 总体校准变换后独立抽取细胞，并用守恒整数分配保持声明的行文库；尚未完成候选比较，不宣称通过。

验收检查分三部分：期望响应的偏差、有限 n 抽样方差、细胞级分布与官方 DE。生成均值随随机种子自然波动，不能通过钉死每批基因总量提高表面均值精度；检出率、稀疏度和均值方差关系按深度联合诊断，不能强制所有扰动与 NTC 相同。零 Delta 必须退化为同随机流的经验 NTC 抽样。

输出满足完整轴、有限非负整数、每靶 400 细胞、文库上界及部署文件的稀疏存储限制。模型内部可预测连续参数，整数化在观测生成端完成。[官方提交要求](https://vcc-cli-wiki.virtualcellchallenge.org/#submission-requirements-2026)

## 本地评估

### 划分和参考群体

正式评价使用五背景 S2 LOCO、S3 背景与全局靶点双留出，并单报三个来源研究的 S4。每个独立拟合有独立 run；S3 的留出靶点须从所有 source 监督中移除。超参、HVG、先验 PCA、剂量模型及早停仅用内层 source 折。目标只暴露 input NTC；score NTC 及目标扰动表达仅供评分侧使用。

**正式比较采用每折全部结构合格的留出靶点**，具体清单来自冻结 split manifest；官方重叠靶点单列。旧 16 靶面板保留作已完成接口诊断。需要快速开发时可预先固定较小的身份哈希面板，但不根据响应强度、DE 数、anchor 质量或模型表现挑选；小面板晋级后须回到全折评价。

每个参考群体只构建一次完整的官方 baseline 和五次 split-half anchors；候选复用同一内容哈希的 bundle。扩展至全折参考是一个新的有限批次，必须新 run、新配置、新 anchors；不能复用旧 16 靶标尺。扩大面板也可能失败，预算不扩展成不断换种子/人群寻找有效标尺。

### 三个观察范围同时报告

| 范围 | 真实细胞与深度 | 用途及边界 |
|---|---|---|
| 全折主范围 | 每靶 min(n,400)，任务深度视图，预测 400 | 所有合格任务的迁移评价；公共数据仍有功效和 assay 差异 |
| 充分细胞范围 | 原本 n≥400 的任务，各取 400 真实细胞 | 更接近目标细胞数；属于有选择偏差的子群，不替代全折 |
| 功效诊断范围 | 固定 400 个预测细胞，抽到对应真实 n | 定位显著性差异的细胞数成分；不当成正式提交分数 |

附加按真实 n 的 `[4,32)`、`[32,100)`、`[100,400)`、`400` 分层；分层是报告范围而非新增过滤条件。响应强度/效率分层只作评分解释，不回流模型。改变面板做六指标评分时重新构建相应 anchors；只汇总逐靶诊断时明确它不是子面板官方 Overall。

### 指标与能力判据

固定 `cell-eval2@5e64833518a6603a0301cbe28185d49c30f4a986`、`vcc2026` 和已有冻结 recipe。报告六项 raw、normalized、Overall、截断前表达误差、逐靶有效数与覆盖。官方靶点排除、gate、LFC 方向及聚合公式直接调用官方实现。没有有效标尺的面板保留原始诊断和未定义 Overall，不平均剩余分项，也不把跨面板 Overall 当作同一标尺。[官方指标说明](https://github.com/ArcInstitute/cell-eval2/blob/5e64833518a6603a0301cbe28185d49c30f4a986/docs/vcc2026_metrics/vcc2026-metrics-brief.md)

每次候选至少配：零 Delta、只用允许 source 的均值/模板、相同信息的简单预测器、冻结预测的靶标签置乱；实测复制和目标真值模板仅作为 evaluator oracle。使用配对生成种子，训练随机性另报。报告预测/真实 DE 数、错误方向、漏检，以及去模板残差的误差、相关性和幅度；低残差方差时相关性可未定义，不能只看相关系数。

模板子空间优先由训练 source 定义，正式能力诊断不读取外层标签拟合它。可附加已登记的评分侧半面板 oracle 模板，并在另一半诊断，禁止进入预测器。通路沿用冻结 Reactome、至少五个实测成员、原始及残差恢复，单报 coverage；后续增加 Hallmark 须另固定来源。只减一个共同 centroid 不等于移除模板方向。

模型晋级须同时满足：计数与零响应校准通过；在相同参考/生成条件下优于可部署简单基线；靶标签置乱削弱收益且去模板诊断支持扰动特异性；收益不只来自一种 n/深度子群；确认范围内的配对收益超过预定测量及训练波动。具体最小效应与容差在候选运行前用训练/校准范围冻结，不借用官方旧面板的波动百分比作为通用阈值。

缺失某折 normalized 分数不阻止生成其他有效结果，但限制总体/跨研究结论。报告共同有效面板上的配对结果及缺失清单；不为每个模型选择不同有效集。公共五背景已被反复用于开发，不能再称未触碰的最终测试集；最终外推仍需独立背景/官方冻结提交核查。
