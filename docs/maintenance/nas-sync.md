# 手动同步仓库到 NAS 并释放本地大文件

[同步脚本](../../scripts/sync_to_nas.py)将当前仓库复制到 `/mnt/projects/virtual-cell-challenge`，复制成功后仅把同时满足 **未纳入 Git 版本控制且大小严格大于 1 GB** 的本地普通文件替换为指向 NAS 同位置的绝对软链接。1 GB 按十进制 `1,000,000,000` 字节计，等于该大小的文件保留本地实体。Git 管理的文件及 `.git/` 全部复制，但始终保持本地实体；嵌套仓库/子模块的跟踪文件同样排除。选择条件固定，不能用命令行参数调低阈值。

从本地仓库执行：

```bash
cd ~/Downloads/virtual-cell-challenge

# 预览：不修改本地树或 NAS 树
/home/jy001/micromamba/envs/virtual-cell/bin/python scripts/sync_to_nas.py --dry-run

# 手动开始：同步完成后自动校验并替换大文件
/home/jy001/micromamba/envs/virtual-cell/bin/python scripts/sync_to_nas.py

```

还支持 `--copy-only`（只复制、保留本地实体）、`--checksum`（rsync 对全部普通文件按内容判断是否需要更新），以及 `--source`、`--destination`。默认 NAS 目标始终要求 `/mnt/projects` 确实挂载，防止断挂后意外写回本地盘；其他目标可通过 `--require-mount` 指定必须存在的挂载点。

## 同步范围与文件安全

- 覆盖整个工作区，包括隐藏文件、`.git`、未跟踪文件、被 Git 忽略的数据、模型、缓存、输出和 `.venv`。这不是只同步 `git ls-files` 的代码副本。
- 已经指向 NAS 对应位置的软链接不再复制，保留 NAS 上的实体文件/目录；后续重复运行不会把它们变成自指链接。预先存在的悬空 NAS 链接保留并列入 `missing_nas_links`，不宣称已经恢复其中的数据。
- 使用增量 rsync，不执行 `--delete`，保留 NAS 独有的数据和未完成下载。覆盖的旧文件放在 NAS 的 `.nas-sync/backups/<本次编号>/`；备份不会自动清理。
- 复制保留权限、时间戳、硬链接关系及稀疏文件内容，不修改 owner/group。源树内部的绝对软链接在 NAS 副本中改指向 NAS 内部；外部链接保留原指向，不把链接外的目录一并下载或复制。
- 只有 rsync 成功后才开始迁出大文件。每个候选都完整读取本地与 NAS 副本，比较 SHA-256、大小和前后文件身份，再以原子重命名发布软链接。复制失败、哈希不一致或文件变化时停止；未经验证的本地实体保留。
- 纳入版本控制以实际 Git 索引为准，不只是看 `.gitignore`；扫描和替换前均检查。若复制或校验期间文件被 `git add`，保留本地实体。
- 每次执行在 NAS `.nas-sync/<本次编号>.jsonl` 写入开始、逐文件校验/替换和完成或失败事件；源与目标的哈希保存在事件中。中断后可用相同命令重跑，已替换的文件通过 NAS 链接跳过，未替换的文件重新校验。

若提示 `SHA-256 mismatch`，本地文件仍在；使用 `--checksum` 重跑，让 rsync 修复大小/时间戳相同但内容不同的 NAS 副本，然后再次完整校验。

## 执行条件与空间口径

**在没有训练、环境更新或其他写入工作区的时段运行。**脚本用锁阻止两个同步同时修改同一 NAS 目标，并检查 Git 锁与可见的文件写入句柄，但这不能冻结所有外部进程，也不能生成正在运行任务的一致快照。已有 NAS 数据目录内的独立下载由对应软链接隔离，仍应避免同时修改需要同步的本地日志、登记或代码。

大文件校验会读取两份完整内容，首次同步数 TB 数据可能耗时较长。`offload_bytes` / `linked_logical_bytes` 是文件逻辑长度之和；稀疏文件、硬链接、打开的旧文件句柄会使实际释放空间与其不同，以 `df -h` 为准。不大于 1 GB 的文件继续保留本地实体。

替换后的本地路径依赖 NAS 挂载。软链接本身不是独立备份，原始数据和历史产物的保护要求仍然适用。`.nas-sync` 是同步工具保留目录，不复制回源树。

研究引用校验允许读取 `data/` 或 `experiments/<experiment>/outputs/` 内未跟踪文件的 NAS 镜像，要求目标严格位于 `/mnt/projects/virtual-cell-challenge/` 下的相同相对路径，文件存在且原 SHA-256 匹配。代码、已跟踪路径、其他外部位置和含 `..` 的越界引用仍被拒绝；这项兼容不改变同步脚本“未跟踪且大于 1 GB”才迁出本地实体的条件。
